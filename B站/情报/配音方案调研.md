### 坑 1：`nvidia-smi` 的显存数在这台机器上不可信（实测）

```
$ nvidia-smi --query-gpu=memory.used,memory.total,utilization.gpu --format=csv,noheader
15610 MiB, 16303 MiB, 100 %

$ venv\Scripts\python.exe -c "import torch;print(torch.cuda.mem_get_info())"
(14595383296, 17055268864)   ->  空闲 13.59 GB / 总共 15.89 GB
```

`nvidia-smi --query-compute-apps` 对所有进程都报 `[N/A]`，说明这是 Windows WDDM 的记账方式问题，不是真有 15 GB 被占。
**判断「显存够不够」一律用 `torch.cuda.mem_get_info()`，不要用 `nvidia-smi`**，否则会误以为卡满了而不敢跑。

### 2.3 推荐：**IndexTTS-2，脱离 ComfyUI，用独立 venv 直接跑 Python**

**为什么是它（按权重排序）：**

1. **中文效果**：IndexTTS-2 是中国团队（B 站）出的，官方语言列表里中文是第一梯队；Chatterbox / F5-TTS 的中文属于「能说」但不是主场。短剧旁白要的是语气，IndexTTS-2 自带 **8 维情感向量 + 文字描述控情绪**，这是六个候选里唯一把这个做进主模型的。
2. **体积/显存最省**：主模型 **5.49 GB（实测）**，只有 Fish Speech 的一半。实测在 16 GB 卡上跑起来毫无压力（见 §2.4）。
3. **可以完全离线**：模型下完就断网跑，不需要任何 API key。
4. **对 ComfyUI 的破坏最小**：它的 `pyproject.toml` 和本机 ComfyUI venv **硬冲突**（下面第 5 条），所以**根本装不进 ComfyUI** —— 这反而是好事：单开 venv，跑 TTS 完全不动 ComfyUI 的图像/Qwen 环境。

#### 2.3.1 决定性的一招：把整套环境套一个纯 ASCII 的 junction

IndexTTS-2 一开始怎么都跑不起来，根因**不是环境装错了，是路径里有中文**（`B站`）。
两个 C++ 扩展先后栽在这上面（详见 2.4 坑 E、坑 F）：

- `kaldifst`（wetext 的 FST）→ `kaldi-io.cc:Input:744 [E] Error opening input stream`
- `sentencepiece`（`bpe.model`）→ `NOT_FOUND: "...\bpe.model": No such file or directory Error #2`

**同一个文件、同样的字节数，换成纯 ASCII 路径就能打开。** 这类库内部用 `std::ifstream`
按本地代码页开文件，不认中文；Python 自己的 `open()` 走 Unicode API 所以没事——于是表现为
「模型明明在，就是报文件不存在」。

与其给每个库单独打补丁（我给 wetext 打的 `.pth` 补丁就是这种，见 2.4 坑 E），**不如从根上绕开**：
建一个 ASCII 的目录联接（junction），以后一切都从 ASCII 那条路走。

```powershell
# 不需要管理员权限，/J 是目录联接不是符号链接
cmd /c 'mklink /J D:\tts "D:\DSHworkspace\B站\配音环境"'
```

实测效果——Python 认到的全是 ASCII 路径，`wetext` 的 FST 补丁都不需要了：

```
$ D:\tts\venv\Scripts\python.exe -c "import sys, wetext, importlib.resources as r; ..."
  sys.prefix     = D:\tts\venv
  sys.executable = D:\tts\venv\Scripts\python.exe
  wetext at      = D:\tts\venv\Lib\site-packages\wetext\__init__.py
  fsts           = D:\wetext-fsts          <- 早先的 .pth 补丁还在，但不冲突
```

**规矩定了：跑 IndexTTS-2 一律用 `D:\tts\venv\Scripts\python.exe`，模型参数一律传
`D:\tts\models\IndexTTS-2`，`PYTHONPATH` 一律用 `D:\tts\index-tts-src`。
中文路径 `D:\DSHworkspace\B站\配音环境\...` 只在人看的时候用。**

**顺带一条**：跑 TTS 前必须腾显存，实测命令和结果：


### 2.4 实测记录：装和跑踩过的坑（每条都是真报错）

**坑 A：`huggingface_hub` 新版默认走 Xet 后端，直连 401**

```
RuntimeError: Task error: File reconstruction error: CAS Client Error:
Request error: HTTP status client error (401 Unauthorized),
domain: https://cas-server.xethub.hf.co/v2/reconstructions/...
```

① 把 FST 数据复制到纯 ASCII 路径：


- `.pth` 里的可执行行**必须写在一行**。
- lambda 里引用的名字**必须做成默认参数**（`_P=_pl.Path`）——`.pth` 是在一个用完就丢的命名空间里执行的，闭包引用全局名会报 `NameError: name '_pl' is not defined`（这个错我实测踩到了）。

`pcm_s16le` 编码、`容器.mux(包)`。**这套写法跟 `配音.py` 里是同一套，已经反复验证过。**

效果（实测）：

装完还得再弄 ffmpeg，又回到「本机没有 ffmpeg」的死循环。PyAV 是现成的，改 30 行更省事。

## 4. C. 把声音和画面合起来：`配音.py`

**路径：`D:\DSHworkspace\B站\制作\配音.py`**（全中文命名，风格对齐同目录的 `视频拼接.py`）。

```python

    print(f"   ⚠ BGM 未处理（{args.bgm}）—— 需要单独混音步骤")
```

### 4.1 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--视频` | 必填 | 无声 mp4 |
| `--旁白` | `[]` | **可多个，按顺序拼**（`nargs="+", action="extend"`） |
| `--bgm` | 无 | 背景音乐（mp3/wav 都行），不够长自动循环 |
| `--bgm音量` | `0.18` | BGM 增益 |
| `--旁白音量` | `1.0` | 旁白增益 |
| `--原声音量` | `1.0` | 视频自带音轨的增益（源视频没音轨时自动跳过） |
| `--旁白起始` | `0.0` | 第一句旁白从第几秒开始 |
| `--间隔` | `0.25` | 两句旁白之间的静音间隔 |
| `--超长处理` | `延长视频` | `延长视频` / `裁掉` / `报错` —— **处理「旁白比视频长」** |
| `--目标时长` | 自动 | 手动指定总时长 |
| `--编码速度` | `veryfast` | x264 preset |
| `--输出` | 必填 | 成品 mp4 |

**「旁白比视频短」**：音轨尾部补静音到视频长度，画面**直拷不重编码**（快）。
**「旁白比视频长」**：默认 `延长视频` —— 重编码画面并把**最后一帧冻住**补到旁白长度；也可以 `裁掉` 或 `报错`。

### 4.2 实现要点（为什么这么写）

- **全程 PyAV，不碰 ffmpeg 命令行**（本机 ffmpeg 不在 PATH）。
- 混音统一在 **48000 Hz / stereo / fltp** 下做：每条输入都过 `av.AudioResampler(format="fltp", layout="stereo", rate=48000)`，所以不同采样率、单声道/立体声的素材可以随便混。
- BGM 用 `np.tile` 循环铺满，首 0.8 s 淡入、末 3.0 s 淡出，避免爆音。
- 混完查峰值，超过 **0.891（−1 dBFS）** 就整体降下来（限幅），不削波。
- **PyAV 18 的破坏性变更**：`OutputContainer.add_stream(template=...)` **已被移除**，实测报
  `TypeError: add_stream() takes at least 1 positional argument (0 given)`。
  替代 API 是 **`add_stream_from_template(Stream template, bool opaque=None, **kwargs)`**。脚本用的是这个。
  （另：`inspect.signature()` 对这些 Cython builtin 无效，只能读 `__doc__`。）
- 退出码：`0` 成功 / `1` 参数或素材问题 / `2` 混音编码失败。
