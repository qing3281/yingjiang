## 0. 一句话结论

**番茄小说网页端的正文可以零成本、无需登录、无需签名地拿到，唯一的障碍是 PUA 动态字体混淆，而我已经把它彻底解开了。**
但**版权上不安全**，直接拿原文去 B 站投稿属于侵权。
所以推荐方案是：**用「番茄等平台」当题材与结构的灵感库（只看不搬），用「公版古籍语料」当可合法改编的素材底座**——

## 2. 路径 1：番茄小说网页端（能用）

### 2.1 页面数据是服务端渲染（SSR），不是 XHR

实测（`curl_cffi` `impersonate="chrome124"`，无 cookie、无登录）：

```
首页       HTTP 200  140,929 B  window.__INITIAL_STATE__ ×1   /page/ 链接 23 个
详情页     HTTP 200  167,446 B  /reader/ 章节链接 351 个（去重）
            <title> = 部族荣光完整版在线免费阅读_部族荣光小说_番茄小说官网
阅读页     HTTP 200   29,130 B  正文在 __INITIAL_STATE__.reader.chapterData.content
```

- 正文**不在可见 HTML** 里，而在内联的 `window.__INITIAL_STATE__` JSON 中，`content` 字段是 `<p>…</p>` 片段。
- `reader.chapterData` 有 26 个字段：`title / bookName / bookId / itemId / order / chapterWordNumber / isChapterLock / isPaidPublication / needPay / author / creationStatus / …`
- `robots.txt` 全文只有两行：`User-Agent: *` + `Allow: /`（**全站放行**）。

> 结论：**不需要任何 API、不需要签名、不需要 cookie**，一个 GET 就能拿到结构化章节对象。

### 2.2 唯一的障碍：PUA 动态字体混淆 —— 已完全解开

正文里约 **47% 的字符**被替换成 Unicode 私用区（PUA）码位：

```
明文「盘虚宇宙，宇宙极。」→ 实际下发「盘虚宇宙，宇宙\ue3fa极。」
```

取证结果：

| 项目 | 实测值 |
|------|--------|
| `@font-face` 条数 | 6 条（1 个 family × 3 权重 × 正常/斜体） |
| font-family | `DNMrHsV173Pd4pgy` |
| woff2 路径 | `https://lf{3,6}-awef.bytetos.com/obj/awesome-font/c/dc027189e0ba4cd.woff2` |
| 字体自称 | `This is a subset font of SourceHanSansSC-Normal. © 2014-2020 Adobe`，SIL OFL 1.1 |
| cmap 条目 | 362 个，**全部落在 PUA 区 U+E3E8 ~ U+E55B**，含 10 个空洞 |
| 字体内部自解 | ❌ 不可能：字体里**不含任何明文字形** |
| **跨书跨章一致性** | ✅ **4 本不同的书 × 随机章节，font-hash 恒为 `dc027189e0ba4cd`，font-family 恒定** |

> **最关键的一条结论**：这不是「每本书一张表」，也不是「每次请求随机」，
> 而是**全站共用同一张固定映射表**——解密一次，永久有效。

### 2.2.1 跨书通用性：已用两本不同类型的书正面验证

这是「一张表能不能打天下」的决定性测试（`剧本来源_82_跨书PUA一致性.py`）：

```
《部族荣光》（玄幻）  正文 4223 字  PUA 字符 2244  不同码位 248  未映射 0 个 ✅
《娇养玫瑰》（现言）  正文 1913 字  PUA 字符  949  不同码位 190  未映射 0 个 ✅
   两书码位范围都是 0xE3E9 ~ 0xE55B
   共有码位 167（玄幻独有 81、现言独有 23 —— 只是用字不同，码位空间一致）
```

> **结论：同一张 363 项映射表，对玄幻和现言两个完全不同题材都做到「未映射码位 0 个」。**
> 落地含义：**抓任意一本书都不需要重新解密字体**，`fanqie_font.py` 里的表就是全站通行证。

### 2.3 解密方案怎么走通的（过程与教训）

走了三条路，前两条失败、第三条成功：

| 尝试 | 方法 | 结果 |
|------|------|------|
| v1 | 拿系统字体（SimSun/微软雅黑等 6 种，各 2.7 万字形）做**轮廓坐标精确指纹**反查 | ❌ 0/362 命中 —— 参照字体族错了 |
| v2 | 改用**包围盒归一化 + 24×24 栅格化 + 汉明距离**，用 NotoSansSC 匹配 | ⚠️ 部分：wght400 命中 23/362（6.4%），且版本轮廓有微扰 |
| **v3** | **把 362 个 PUA 字形渲染成图，直接视觉识别** | ✅ **成功** |

v3 的具体做法（可复现）：

1. `woff2` → `ttf`（fontTools 清 flavor 后 save）
2. 用 PIL 以该字体自身渲染每个 PUA 码位 → 20 张字形表 PNG（每格 1 字 + 紧贴的码位标签）
3. 视觉识别读出汉字（字形就是标准思源黑体，非常清晰）
4. **再用 20 章真实语料做逐码位上下文核对**（把其它 PUA 替成 `#` 占位，只还原目标字），对读不通的位置定罪修正
5. 最后用**词表命中率做贪心优化**，逐项接受净提升的改动

教训（写下来避免下次踩）：
- 密集字形表**一次性目视转录不可靠**，会出现整体错位一格；
- 只有「**单格渲染 + 紧贴码位标签**」的小样图才可靠；
- 必须用**真实语料上下文**做二次校验，光靠字形会错；
- 网上找到的公开映射表（`ying-ck/fanqienovel-downloader` 的 `src/charset.json`）**本身就有整体偏移**，直接抄会错（实测用它对拍，短语命中从 133 掉到 12）。

### 2.4 最终效果（实测输出）

映射表固化后接进 `fanqie_font.py`。**最终验收（`剧本来源_83_最终验收.py`，2026-10-12 实测）**：

```

《娇养玫瑰》（现言）  正文 1913 字  PUA 字符 949/1913
  未映射码位 0 个 -> 残留乱码率 0.0000%     ✅
```

成品样例（真实输出，未做任何人工修饰）：

> 深色窗帘一角被掀了缝隙，月光泄进来。落地窗前，男人穿着件黑色衬衫，身姿修长，锋利利挺的下颚线条被冷色月光切割的分明。棠梨趴在床上，望着男人坚情宽阔的后背，心跳的有些快。男人转过头，神色冷倦，眉骨凌厉分明，一双桃花眼带着冷感，瞳仁很黑，睛光透着点漫不经心的欲。他走到床边，俯下身，伸手扣着她的下巴，扬了下眉，"心跳的么么快？"棠梨呼吸微紧，男人轻笑了声，覆着黑色佛珠的冷白腕骨抵着腰间，盯着她的眼睛，漫……

**说明**：`未映射码位 0` 的含义是「**所有 PUA 字符都有对应汉字**」。
文本里仍有极少量**语义错字**（如 "锋利利挺" 应为 "锋利利落"、"坚情" 应为 "坚挺"、
"么么快" 应为 "这么快"），来源是少数码位映射到了形近字，**约 1~2% 字符**。
→ **完全够用**于「读梗概、抓结构、看题材」，**但不适合逐字照搬**（版权上也不该照搬）。

### 2.5 覆盖边界：锁章拿不到（这条决定用途上限）

这不是反爬，是**书籍授权状态**。实测同一本书抽样 12 章：

```
第 1章  锁    实得 162 字
第 2章  免费  实得 4223 字
第 3章  免费  实得 3395 字
  …（第 2~11 章全部免费，正文完整）…
第12章  锁    实得 162 字
  -> 免费 10 章、锁定 2 章
```

锁章 `isChapterLock: true`，只给约 160~200 字试读。**免费章能拿全，付费/锁章拿不到。**

### 2.6 反爬设施现状（实测未触发）

从首页内联脚本取证到的风控设施：

- 字节 **Argus** 风控：每个页面都带 `nonce="<32位hex>-argus"` 的内联脚本
- 腾讯/字节验证码 SDK：`lf-c-flwb.bytetos.com/obj/rc-client-security/sec_sdk_build/3.8.0/captcha/index.js`、`TTGCaptcha.init({aid:2503,...})`
- `secsdk`：`lf-security.bytegoofy.com/obj/security-secsdk/runtime-v1.0.0.js`、`lf1-cdn-tos.bytegoofy.com/obj/goofy/secsdk/secsdk-lastest.umd.js`
- 埋点：`mon.zijieapi.com`；`bdms.paths: ["/api", "/reading/user/redeem_code/use"]`
- CDN：`server: volc-dcdn`

**实测结论**：在 **1.2~2.0 秒**请求间隔下，全程 HTTP 200，**未触发验证码、未封 IP**。
（拿到多少内容取决于书是否免费，不取决于反爬强度。）

⚠️ 但 `fanqienovel.com/api/reader/directory/detail` 这类端点会返回 **HTTP 515**，说明 `/api` 路径受 tRPC/Argus 保护，**不要硬刚接口，走 SSR 页面**。

## 3. 路径 2/3/4：API 与开源生态（不通 / 要绕）

### 3.1 移动端 App API —— 全部裸调失败

带安卓 App UA（`com.dragon.read/6.0.0`）、无 cookie 实测：

| 端点 | 结果 |
|------|------|
| `https://fanqienovel.com/api/reader/full?itemId=…` | 200 但 body 长度 **0** |
| `https://fanqienovel.com/api/reader/directory/detail?bookId=…` | **HTTP 515** |
| `https://novel.snssdk.com/api/novel/book/reader/full/v1/?item_id=…&aid=1967` | 200，body **0** |
| `https://novel.snssdk.com/api/novel/book/directory/list/v1/?book_id=…&aid=1967` | 200，body **0** |
| `https://novel.snssdk.com/api/novel/book/detail/v1/?book_id=…&aid=1967` | **404 Page not found** |
| `https://novel.snssdk.com/api/novel/book/reader/batch_full/v1/?item_ids=…` | **404** |
| `https://api5-normal-sinfonlineb.fqnovel.com/reading/reader/full/v1/?item_id=…&aid=1967` | 200，body **0** |

> 结论：**所有 App 端点都需要签名头（X-Gorgon / X-Argus / X-Ladon / X-Khronos 这一族）**。
> 裸调返回空 body 是「签名校验失败后静默返回空」的典型行为，不是端点写错了。

签名算法本身在 GitHub 上有研究项目（`ssovit/x-gorogn-khronos-argus-ladon` ★354、
`armxe/tiktok-api` ★330、`SyntaxSparkk/TikTok` ★744，都是 TikTok/抖音 系列，**已停更 2023~2025**），
但**把这些移植到番茄且保持可用**是一个持续的逆向工程负担，**不建议**。

### 4.4 ctext.org ❌

`https://api.ctext.org/gettext?urn=ctp:analects/xue-er` → HTTP 200 但内容是：

```json
{"error": {"code": "ERR_REQUIRES_AUTHENTICATION", "description": "..."}}
```

**所有 URN 都一样**，必须注册账号拿 API key → 按约束（不写需付费/需 key 方案）**排除**。

## 6. 法律与风控边界（必须守住）

### 6.1 危险用法 ❌ —— 不要做

| 行为 | 为什么危险 |
|------|-----------|
| 照搬原文（哪怕改几个字）去生成视频投稿 | 直接侵犯**复制权 + 改编权**，B 站收到投诉会下架+扣分 |
| 沿用原文的**人物名 + 独创性设定**（如「棠梨」「傅清扬」「九爷」「洛神」） | 人物名与独创性角色设定受保护，**即使重写剧情也可能构成侵权** |
| 照搬**具体桥段序列**（情节的独创性表达，不只是思想） | 思想/表达二分法里，「具体到足以构成表达的情节链」受保护 |
| 拿锁章/付费章内容 | 额外还绕过技术保护措施，性质更重 |
| 高频批量抓取番茄正文建库 | 违反平台规则；社区项目自己都写「不建议高频批量滥用」 |

### 6.2 安全用法 ✅ —— 可以做

| 行为 | 说明 |
|------|------|
| **只取「题材 / 梗概 / 结构 / 情绪节拍」** | 题材和通用套路（霸总、重生、复仇、打脸）**属于思想**，不受版权保护 |
| **用公版作品**（古籍、清代以前小说、Project Gutenberg 美国公版书） | 公有领域，可自由改编甚至商用 |
| **从公版作品做「现代化重写」** | 改写后的表达是**你的原创**，只要不复用他人现代译本/注释 |
| **自己原创**（用 LM 按结构模板生成） | 版权最干净，且与流水线天然契合 |
| **参考热榜/榜单做选题** | 选题方向不受保护（这也是 `情报/` 目录既有流程） |

> 一条简单的自检规则：**「我看的是梗概和节拍表，还是具体句子和角色名？」**
> 前者安全，后者危险。

## 7. 推荐方案

### 7.1 主路径：**公版短篇集 + LM 现代化重写 + 三段式结构模板**

```
殆知阁 / 维基文库（公版短篇：聊斋志异、阅微草堂笔记、三言二拍、搜神记…）
        ↓  只取「梗概 + 人物关系 + 反转点」（不取句子、不取角色名）
   本地 LM（qwen3.5-9b，已是现成流水线）
        ↓  按 3 分钟短剧结构模板重写，人物全部重新命名
   《脚本.json》→ Z-Image-Turbo 出图 → 出片 → 投稿 B 站
```

**为什么这条最好**：
1. **版权干净** —— 公版作品 + 原创改写，可商用、可投稿、不怕投诉
2. **篇幅天然匹配** —— 聊斋/阅微的「一则」就是 300~2000 字，正好一个 3 分钟短剧
3. **已实测可用** —— GitHub raw 直链无限制、维基文库 API 可用（加重试）
4. **零新增依赖** —— 纯文本，不需要字体解密、不需要签名、不需要付费 key
5. **和现有流水线无缝** —— 现有的 `写脚本.py` 只差一个「读素材 + 套结构」的输入环节

### 7.2 辅路径：**番茄热榜/免费章只做「选题雷达」**

- 用已跑通的 `fanqie_reader.py` **只看**：哪些题材/人设/开局钩子在番茄上跑量
- 提炼成「题材标签 + 情绪节拍」，喂给 LM 当**风格指引**
- **不落盘原文、不进素材库、不参与生成**

### 7.3 3 分钟短剧结构模板（可直接喂给 LM）

```
0:00-0:20  钩子：一句台词/一个异常画面，制造疑问
0:20-1:00  处境：主角身份 + 压迫源（谁在欺负他/她）
1:00-1:40  升级：冲突加码，主角被逼到墙角
1:40-2:20  反转：身份/实力/真相揭晓，攻守易位
2:20-2:45  打脸：给出爽点，兑现前面的承诺
2:45-3:00  钩子：留一个未解悬念（为下一集/涨粉）
```

适合 AI 生成、不依赖复杂实拍场景的题材（按改编难度排序）：

1. **古风志怪**（聊斋型）—— 单场景、强反转、人物少 ✅ 最推荐
2. **公案/断案**（阅微型）—— 对话驱动，无需动作场面
3. **世情讽刺**（三言二拍型）—— 现代职场/家庭可平移
4. **神话寓言**（搜神记型）—— 强符号感，适合 AI 画面
5. **重生/复仇**（番茄主流）—— 结构模板成熟，但**必须完全原创**
6. **身份反差打脸**（番茄主流）—— 同上
7. **民间奇谈**（地方传说/奇闻）—— 公版，且天然有地域感

**③ 中文维基文库取公版短篇（必须加重试，实测会超时）：**

```python
import json
import time
import urllib.parse as up
import urllib.request as u

def wikisource(title: str, tries: int = 4, timeout: int = 45) -> str:
    """取中文维基文库页面正文 HTML。实测偶发超时，必须重试。"""
    url = ("https://zh.wikisource.org/w/api.php?action=parse&prop=text"
           "&format=json&redirects=1&page=" + up.quote(title))
    for i in range(tries):
        try:
            with u.urlopen(u.Request(url, headers={"User-Agent": "drama"}),
                           timeout=timeout) as r:
                d = json.loads(r.read())
            return d.get("parse", {}).get("text", {}).get("*", "")
        except Exception:
            time.sleep(2 * (i + 1))
    return ""

html = wikisource("喻世明言")
print(len(html))
```
