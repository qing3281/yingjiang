# 出门在外怎么看产出 / 收产出

两条路，**都不用管理员权限**。

---

## 路线 A（推荐）：QQ 邮箱 —— 我在家推，你在外面收

上班、在外面、用流量，都能收。剧本 / 图片 / 视频（自动压到手机能放的大小）都能寄。

### 你要做的（两分钟，只做一次）

1. 电脑或手机浏览器打开 **mail.qq.com**，登你的 QQ 邮箱
2. 左上角 **设置 → 账户**
3. 找到 **「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务」**
4. 把 **「IMAP/SMTP服务」** 打开（会让你用手机发条短信验证，跟着走）
5. 开完会弹出一个 **16 位的授权码**（一串字母），**复制它**

> ⚠️ 授权码不是你的 QQ 密码。它只给「发邮件」用，随时能在同一个页面点「删除」作废。

6. 回来跟我说一句：

```
邮箱通道：<你的QQ号>@qq.com  授权码 <那16位>
```

我跑一次 `寄邮件.py --设` 存下来，再 `--测` 发一封测试信，你收到就成了。

### 之后我会怎么用

| 场景 | 我寄什么 |
|---|---|
| 剧本定稿 | 正文放剧本全文，附件放人设图 |
| 分镜预览 | 首帧拼图 + 封面候选，正文写每镜要点 |
| 成片 | 原片（>48 MB 就自动压一版 960 宽的手机版，约 9 MB）当附件 |
| 出问题 | 报错原文 + 截图，正文写我打算怎么修 |

单封上限按 QQ 的 50 MB 算，超了自动拆成多封或压手机版。

### 邮件这条路的优点 / 缺点

- ✅ 不用管理员、不改防火墙、不在家也能收
- ✅ 有存档，翻历史就行
- ✅ 附件能带图能带视频能带文档
- ❌ **只能我发你**，你在邮件里回我，我看不到（收信要另配）
- ❌ 想看我**实时**的东西还是得回家连 WiFi

### 这条路要注意

- **只在家里的 WiFi 下有用**，出门换成流量就打不开了
- 我为了让它能被手机访问，加了一条防火墙放行规则（`看成片-8777`，只放 TCP 8777）。你说了少搞要管理员的东西，**这条是唯一一条**，要撤掉随时说：
  ```
  Remove-NetFirewallRule -DisplayName '看成片-8777'
  ```
  撤掉之后本机自己还能看（`http://127.0.0.1:8777`），只是手机连不上。
- 服务关了就没了，要重开就跑 `python 看成片.py`（在 `D:\DSHworkspace\B站\制作`）

## 你说「用 QQ 也行的」

QQ 本身（聊天窗口）我没法自动发 —— QQ 没有公开的、不装协议端就能发文件的接口。
能自动化的 QQ 通道只有两个方向：

1. **QQ 邮箱**（就是路线 A）—— 手机 QQ 里也能直接看邮箱，等于还是 QQ
2. **QQ 机器人 / NapCat 这类协议端** —— 要拿小号登一个第三方客户端，风险大、也容易封号，**不建议**

所以路线 A 就是「用 QQ」的那条路：寄到你 QQ 邮箱，你在手机 QQ 里点开「QQ邮箱提醒」就能看图看视频。
