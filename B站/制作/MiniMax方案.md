# MiniMax 短剧方案

> 这份方案里每一个数字都是这台机器上实测出来的，不是估的。实测记录见本文末尾。

---

## 一句话

**每个镜头 = 一张 Z-Image 定妆图 + 一句中文台词 → MiniMax 出 5.17 秒带声音的视频。**

---

## 数据流

```
剧本.json
   │
   ├─[1] Z-Image 逐镜出定妆图        角色锁，约 5 秒一张，已有
   │
   ├─[2] MiniMax fl2va 逐镜出片      定妆图 + 台词 → 5.17 秒带音轨，实测 151 秒一镜
   │
   ├─[3] 质检                        首帧比对 + Whisper 回读台词，不合格的重摇
   │
   ├─[4] 拼接                        硬切，音频连续拼接
   │
   └─[5] BGM 垫底 + 烧字幕（可选）
成片.mp4
```

---

## 为什么这么设计

| 设计决定 | 实测依据 |
|---|---|
| 每镜固定 **124 帧 / 5.17 秒** | 官方可用范围 124–362 帧。124 帧实测 **151 秒**跑完；362 帧（15 秒）跑了 **30 分钟只走到第 4 步中的第 1 步**，约 19 倍慢，实际不可用 |
| 用 Z-Image 定妆图**钉首帧** | 输出第 1 帧与输入图差 **4.24/255**，脸、衣服、走廊、灯光完全钉住 |
| **不需要 TTS** | MiniMax 自带音轨。Whisper `base`+`small` 双模型一致听出「你在哪里我等了你三个小时了」，中文完全可懂 |
| **不需要旁白表** | 音画在同一扩散过程里联合生成，天然同步，不存在"配音对不上口型"这一类问题 |
| **每镜独立生成**，不做续拍 | 续拍时首帧权重会压过提示词。独立生成的另一个好处：单镜失败只损失一镜 |
| 保留字幕 | 观众静音刷视频。台词文本本来就在剧本里，零额外成本 |

## 时间与资源预算（全部实测）

| 项 | 实测值 |
|---|---|
| 单镜耗时 | **151 秒**（124 帧，4 步采样） |
| 单镜显存峰值 | **15407 / 16303 MiB**（余 896 MiB） |
| 单镜内存峰值 | **31.6 / 46.8 GB**（余 15 GB） |
| 单镜产物 | 1.32 MB，1920×1080，**自带 1 条音轨** |

**3 分钟成片 = 35 个镜头**

- 纯生成：35 × 151 秒 = **88 分钟**
- 加重摇余量 20%：**约 105 分钟**
- 加出图（35 × 5 秒）+ 拼接：**再加 5 分钟**

**总计约 1 小时 50 分钟。**

## 风险与对策

| 风险 | 对策 |
|---|---|
| 显存只剩 896 MiB，别的程序一占就 OOM | 每镜开跑前 `POST /api/free {unload_models, free_memory}`；生成期间不开别的吃显存的程序；看门狗守着内存底线 |
| 台词被模型改写（实测「也别」→「也不要」） | 台词尽量短、用常见表达；质检用 Whisper 回读，偏差大的重摇 |
| 说话起始时间不可控 | 提示词里写 "after a brief pause, then speaks"；实在不行用末帧续拍把话补完 |
| 35 镜里总有几镜会废 | 每镜生成后**自动质检**：首帧比对 + Whisper 回读；不合格自动重摇，最多 3 次 |
| 硬切拼接处音频会"啪" | BGM 垫底盖住接缝；或每段音频首尾各加 30ms 淡入淡出 |
| ComfyUI 中途挂掉 | 已验证会挂（跑第二镜时进程消失）。对策：流水线里加健康检查，挂了自动重启并**从断点续跑** |

## 实测记录

### 2026-10-13 00:44 第一次验证（命中）

```
首帧   B站\成片\今天别开门\图\01.png
帧数   124  (@24fps = 5.17 秒)
提示词 …slowly looks up toward the ceiling, then speaks in Chinese…「今天也别开门。」

起跑前  显存 1183/16303 MiB   内存 21.2/44%
   ✅ 完成，耗时 151 秒
   峰值 显存 15407 MiB   内存 31.6 GB
   产物 B站\成片\_MiniMax测试\fl2va_首帧钉_151秒_124帧.mp4  (1.32 MB)
   检查：1 视频轨 / 1 音频轨 / 时长 5.17 秒
```

**首帧钉住验证**：输出第 1 帧 vs 输入 `01.png` → 逐像素平均差 **4.24/255**

**动作跟随验证**：提示词写了 "slowly looks up toward the ceiling"。抽 6 帧看，从第 0 帧低头 → 第 123 帧头完全仰起看天花板。**动作确实跟着提示词走。**

**中文对白验证**：Whisper 听出「今天也不要开门」（我写的是「今天也别开门」）。**语义完全正确，用词被模型轻微改写。**

### 2026-10-12 22:34 电话亭（用户认可的基准）

`B站\成片\_MiniMax测试\测试_电话亭.mp4` — 这是用户判断"只有那个质量才达标"的那条。

### 2026-10-12 深夜 15 秒长测（否决）

362 帧那一次：跑了 30 分 14 秒还没完成第 4 步中的第 1 步，`[01:35, 24.00s/it]` 之后就不再前进。**判定：MiniMax 只能出 5 秒。**
