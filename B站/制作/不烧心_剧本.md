## 世界观

**算力街**：一条青石板老街，街两边全是 AI 铺子。街口一块锈铁牌，写着「算力街」。

今年开春，**显存涨价了**。HBM 比 GPU 核心还贵，一张卡的钱够买半条街。整条街的炉子都在烧钱。

**街两边的两家对门铺子：**

| | 左边 | 右边 |
|---|---|---|
| 招牌 | **GPT·算力铺** | **DeepSeek·白饭管饱** |
| 掌柜 | GPT 龙娘（银白长发，青瞳，龙角龙翼，白裙，怀里抱一本印 OpenAI 标的黑皮书） | DeepSeek 鲸鱼娘（**Q 版大头身**，深蓝渐变长发，鲸鳍耳，女仆裙白围裙，抱着一个比她脸还大的白饭碗） |
| 规矩 | 一个 token 一个价，**按真算力算** | 一个铜板管饱，**蒸馏过、量化过、兑过水** |
| 炉子 | 一口青铜大炉，往里塞的是真显卡 | 一口大铁锅，往里倒的是白饭 |

**「烧心」的视觉定义**：用了兑水的便宜 token 之后的反应——额头冒汗、头顶冒乱码方块、眼神失焦、**嘴里吐糊掉的黑色文字块**（答非所问、胡编乱造）。严重时头顶冒烟。
