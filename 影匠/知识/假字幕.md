# 模型把提示词画成了字幕

> 2026-10-14 在《觉醒》上发现并修掉。**74 格里中了 8 格。**
> 这是 H3 这一类视频模型的一个稳定毛病，不是偶发。

---

## 一、它长什么样

成片里，画面底部**凭空多出一行字**。不是你烧的字幕，是模型自己画进像素里的。

而且**字就是提示词里的字**。格56 的动作字段是：

```
他把话说完，抬起来的右手往院子那边比了一下，然后落回册子上
```

画面上出现的是「把话说完」和「往官院那边比了一下」（“院子”被写成了“官院”——它连字都没抄对）。

格55 的动作字段里有「内门执事」，画面上就是「内门执事了一下」。

**英文也照画。** 格56 有一帧底下压着 `The orie the Witk syat of anheut overs.` —— 一串不成词的英文，形状像字幕，内容全是幻觉。

### 三个特征，认它用

| 特征 | 说明 |
|---|---|
| **字是「间歇」冒出来的** | 同一格里有的帧有、有的帧没有。抽稀了必漏 —— 一格至少要看 8–10 个时刻 |
| **字会变** | 格55 从「周执伸子册」变到「内门执事了一下」，像字幕在逐句换 |
| **字数跟着提示词走** | 提示词那句多长，它画多长 |

## 二、为什么是这几格 —— 真因是构图，不是运气

中招的 8 格：13 / 18 / 19 / 26 / 35 / 55 / 56 / 59。

**共同点：画面下缘是一条「大片空白浅色横带」** —— 白桌布、灰桌面、亮石板。
那块地方**本来就是字幕待的地方**，模型看到一块空的、亮的、横的带子，就把提示词填进去了。

反过来，**手、脚、纸、火、器物占着下半幅的格子，一格里都不中**。格18（手按册子）、格26（手举着纸在火上）从头到尾干净。

### ★ 最值钱的一条：这是「分镜没被遵守」的症状，不是独立故障

格56 的分镜（`影匠/作品/觉醒/02-九宫格.md`）本来就写死了：

> **景别**：medium close-up
> **机位**：平视略仰……周执的头和肩膀占画面中间一大块，桌子只在画面最下沿露出窄窄一条
> 画面最下沿只露出桌面很窄的一条……**占不到画面高度的五分之一**

**但是生成出来是一张「低头拍桌面」** —— 没有脸，桌子占满下半幅。
**构图一崩，字幕板就出现了，字跟着就来。**

所以格56 连败九次不是玄学：**它在忠实地执行一个错误的分镜**。
把构图写死回分镜原本的要求之后，**三条全干净**。

**推论：遇到反复出字的格子，先去查那一格的分镜和实际画面对不对得上。** 对不上，修分镜；对得上，才是真的没辙。

## 三、试过没用 / 有用的写法

拿格55 同图同参数只换提示词（脚本 `影匠/_试提示词_字幕.py`）：

| 写法 | 结果 |
|---|---|
| **A 现状**（`{动作}。环境：{光}。A continuous cinematic shot. …`） | **干净** ✓ |
| **B 英文在前**（`A continuous cinematic scene with no text, captions or subtitles anywhere in frame. …`） | **照样出字** ✗ |
| **C 中文当字段**（`Scene brief (the bracketed text is a production note, NOT on-screen text): [action: …`） | **照样出字** ✗ |

**★ 教训：加「不要字幕」的否定词，反而把字幕召唤出来了。**
B 和 C 都是想「声明一下不让它画字」，结果都中了。A 什么都没说，反而干净。
跟 `影匠/知识/假判据族.md` 里那类「越声明越糟」是同一个味道 —— **别在提示词里提「字幕」这个词**。

### 有用的一招：占住画面下缘

脚本 `影匠/_试占下缘_字幕.py`，在提示词里**主动描述画面下缘有什么东西**（人物、衣角、器物压在那里），
把那条空白横带填掉。格55 用它一次治好。

## 四、怎么查（必须成工具，不能靠眼看）

**判据：把文件名烧进画面里，一行一个文件，右边是这一格从头到尾的密集抽帧。**

脚本：`影匠/_逐格查字幕.py`

```
python 工具\_逐格查字幕.py 觉醒                          # 扫 段\ 全部
python 工具\_逐格查字幕.py 觉醒 --格 13,18,19,26          # 只扫指定几格
python 工具\_逐格查字幕.py 觉醒 --来源 _重抽2 --每格几条 9 --步 0.4
```

- 切**底部 26%**（`crop=iw:ih*0.26:0:ih*0.74`）
- **每 0.35–0.5 秒一帧**，一格 9–12 帧
- **任何一帧有字，这一格就带字**

成片也要查一遍：`影匠/_查成片底部条.py`

### ★ 为什么必须把文件名烧进画面

我在这上面栽过一次，代价是重新接了一遍成片：

当时用 `_重抽\` 里 4 个候选拼了张对比图，2×2 排。我**按行数去数，把 #2 那一行认成了 #3**，
于是判「那一格干净」、装了它，重接成片 —— 结果是带字的那一份。

**教训：判断「哪张图是哪个文件」这件事，不能有任何需要推断的环节。**
图和文件之间必须是**烧进像素的、不可争辩的对应**。
这跟 `影匠/知识/假判据族.md` 是同一族：**判据说 OK，但没有真的量到。**

|---|---|---|
| 换种子重抽 | 每格约 3 分钟（本机）/ 3 分钟（远端），两台并行 | **成功率不是 100%**。格55 第二次还是中，格56 连中九次 |

**别指望「多试几次就好了」。** 格56 九连败，说明有些构图的中标率接近 100%。
**先改构图。**

## 六、连带修掉的一个工具缺陷（同一个教训）

`影匠/_成片_觉醒.py` 的「头尾」那一步原来是：

```python
if 参.重接 or not os.path.exists(接好):
```

**看到文件在就跳过。** 于是接片重跑了、中间产物却是一个半小时前的旧的 ——
**四步全报 ✓，成片是旧的。** 我拿着旧成片核对了半天，还差点把干净的格子改坏。

现在每一步都是：

```python
if 参.重接 or 过时(产物, *输入们):
```

`过时()` 判「产物不存在、或者比任何一个输入都旧」，目录输入取目录里 `.mp4/.json/.srt/.wav` 的最新 mtime。
跑完自报一句：

```
✓ 链条新鲜度：每一步的产物都比它的输入新
```

**「产物存在」不等于「产物是对的」。** 这一条和 `假判据族.md` 里「用存在当判据」是同一个坑。

## ★ 2026-10-15 04:50　量出来的：全片 74 格里有 4 格带假字幕（含已经交出去的那版成片）

这回不是靠眼睛，是靠**一个数** —— 脚本 D:\DSHworkspace\工具\_查假字幕.py：

> 逐格取第 2.0 秒那一帧的**下缘 200 像素**（crop=1280:200:0:504），
> 数**三通道都 >= 235 的纯白像素**占比。

这条片子的调子是冷灰、暗部居多，**画面里本来不该有大片纯白** —— 全片 74 格的**中位数是 0.000%**。实测：

| 格 | 下缘纯白占比 | 画面上写着什么 |
|---|---|---|
| 格20 | **1.221%** | 那点热气是画面里 |
| 格36 | **0.934%** | 要还悬半把抬起来 |
| 格29 | **0.910%** | 一个于抬起捂住黑 |
| 格57 | **0.700%** | 往前迈了一步 |
| 其余 70 格 | **0.000%** | 干净 |

**判据的威力全在「中位是 0」** —— 不是「比别的高一点」，是**别人一个白点都没有**。
四个嫌疑格一个不漏，七十个干净格一个不冤，不用人眼过 74 格。

**这四句都是「动作」的味道**（「往前迈了一步」），不是台词 —— 正好印证本文第 2 节那条：
提示词里出现**动作句子**，模型就有可能把那句话当字幕画上去。

**修法**：这 4 格连本机带远端一起重出（--种子偏移 77），出完 python 工具\_查假字幕.py --只量 复量一遍。
