# 多角色片流水线（《磨刀》定型）

> 一句话：**单角色的《雪线》只能拍氛围，多角色的《磨刀》才有戏。**
> 这一页记的是「从四张角色卡到一条能发出去的片子」这条路上，
> 哪些是做对了的、哪些是踩过的坑。**下次要拍新片，照这页抄。**

---

## 一、为什么《雪线》输了，改了什么

《雪线》是**一个演员、一个场景、六句台词、零冲突**。画面不差，但它不是故事 ——
**没有人物关系，就没有戏**。用户的原话是「我要看的是故事，不是你这种单调的场景，没有剧情看个毛线」。

改的四件事：

| | 《雪线》 | 《磨刀》 |
|---|---|---|
| 角色 | 1 个（凌霜） | **4 个**（沈砚/赵崇武/阿七/阿满）+ 周泰 |
| 场景 | 1 个（雪原） | **6 个**（渡口/赵府/听雪楼旧址/茶铺/长巷/柴房） |
| 台词 | 6 句，全是一个人的独白 | **51 句**，15 格是两人对答 |
| 冲突 | 无 | **3 场打斗** + 一个反转（真叛徒是「唯一活下来的同僚」） |
| 天气 | 一直下雪 | 一直下雨，**最后一场雨停**（全片第一次暖光无雨） |

## 二、四步走（每步的脚本）

```
01-节拍拆解.md  ──┐
02-九宫格.md    ──┼─→ _出片.py --图   ──→ 01_格N.png（45 张首帧）
03-台词.md      ──┘         │
                            └─→ _出片.py --段   ──→ 段\格N_<线>.mp4（45 段）
                                                        │
                            _拼片.py  ────────────────────┤
                                                        ↓
                            片\《磨刀》成片.mp4
                                                        │
                            _配片.py  ──────────────────┤
                                                        ↓
                            片\《磨刀》成片_有声.mp4
                                                        │
                            _配片.py --烧字幕 ──────────┘
                                                        ↓
                            片\《磨刀》成片_有声_字幕.mp4
```

| 脚本 | 干什么 | 实测 |
|---|---|---|
| `_出片.py` | 多角色出首帧 / 出段（取代只认一个角色的 `_出长片.py`） | 45 张首帧 **3 分 30 秒**（每张 3.6–5.2 秒） |
| `_拼片.py` | 双线收段 → 接片 | 45 段 |
| `_配片.py` | 逐句配音 → 混音 → 可烧字幕 | 51 句 |
| `_烧字幕.py` | 烧硬字幕（`force_style` 内联，不写 .ass） | |
| `_联系表.py` | 45 张缩略拼一张，一眼看全部景别 | |
| `_选音色_磨刀.py` | 按**文件名关键词**给每个说话人挑音色，并逐个真解码验 | 7/7 命中 |

## 三、四个必须记住的坑

### 坑 1：锚点词典缺词会**静默丢词**（最坑的一个）

`角色库.py` 的 `_译()` 译不出来就把那个词**丢掉并只报个警**，不报错、不中断。
后果是：你写「灰白短发、贴着头皮」，译不出来 → 提示词里**根本没有头发这一句**，
模型自由发挥，**出图看着还挺好，只是不是你要的那个人**。

**排查方法**：`角色库.外貌串('角色名')['串']` 打出来看 —— 中文词一个都不该剩在里面。
**修法**：往 `角色库.py` 的 `_词典` 里补词（已从 ~90 条扩到 354 条，见 `作品\磨刀\_锚点体检\`）。

> 更阴的一层：**你「建角色」那次词典是全的，之后每次跑都是新进程、词典回来了**。
> 所以词必须写进 `角色库.py` 源文件，写在别处的「临时补词」出了这个进程就没了。

### 坑 2：大远景里**一个锚点都不能喂**

只要提示词里出现「一个人」的锚点串（哪怕缩成 `a single lone figure, long silver-white hair…`），
模型就会把那个 figure 画成画面里**一个实打实的大活人**，再配上一个远处的小人 ——
画出来是「两个人」，不是「一个小到几乎看不见的人」。

**规矩**：`景别 ∈ {extreme wide shot, wide shot}` → **不喂锚点**，人物描写交给提示词自己带。
`_出片.py` 里已按这条分支（日志会打 `[远景·不喂锚点]`）。

### 坑 3：同一个格里的多句台词会**全叠在同一个时刻**

起点只按 `(格号−1) × 步长 + 偏` 算的话，格5 的两句、格9 的两句会同时开始 ——
四个人一起从喇叭里说话。**必须让同格的下一句接在上一句真正说完之后**，
而且要用**实测时长**（估短了压字，估长了拖到下一格）。`_配片.py` 的 `格末{}` 表就是干这个的，
越界会报出来。

### 坑 4：人名带括号时，**括号里的字才是这个声音的身份**

台词表写「沈砚（少年）」，直接拿「沈砚」去查映射会命中**成年沈砚的音色**，
而且**不报错** —— 格26 那句十年前的台词就配成了十年后的嗓子。
`_配片.py` 的 `净说话人()` 先拼「括号内+括号外」（→「少年沈砚」）当首选键。

> 连带的一个更普遍的坑：`配音.角色定音色('一个不存在的名字')` **不抛异常**，
> 它把输入原样吐回来，`源` 是空串。拿空串当成功，那个名字就会被送进合成、
> 再被模糊匹配到**一支谁也不知道是什么**的音色。**判断标准是「源非空」，不是「没抛异常」。**

## 四、角色一致性：靠什么撑住

1. **锚点串写进每一格的提示词**（`02-九宫格.md` 里一人 5 个具体锚点，逐字复用）。
   不是靠一张定妆照当参考图 —— 那是 Qwen-Image-Edit 的做法，
   而它的参考隐变量**把构图也一起锁进条件**（喂胸像必出胸像，写 `extreme wide shot` 也没用）。
2. **同一个种子**（`种子=1735946766`）跑全部 45 格。
3. **远景不喂锚点**（见坑 2），近景才喂。
4. **双人/四人同框用 z_image_turbo 直接画**（实测成立，两个完全不同的人在一格里各自锚点都对）。

> 已知没修好的：**阿七的「深靛蓝军服」在部分格里漂成中山装**。
> 军服/官服这类「制式服装」比「一件旧皮围裙」难锁得多。

## 五、双线：远端只出算力

`_出片.py --端点 远端` 与 `--端点 本机` 走**同一份代码、同一份模板、同一个种子**。
已验证（`_双线端到端.py` 三级检查全过）：模型字节数一样、工作流指纹一样、出片规格一样。
**远端只是把 GPU 借出来，效果全部由本机的模板/种子/角色卡决定。**

`_拼片.py` 收段时**两个来源都要数**（`段\格N_本机.mp4` / `段\格N_远端.mp4`）——
只认一种命名会把另一条线出的格**整格漏掉**，接出来的片子短了还不报错（踩过）。

## 六、时长与算力（实测数）

| | 数 |
|---|---|
| 段规格 | 73 帧 @ 16fps = **4.56 秒**，1344×768 |
| 45 段成片 | 45 × 4.56 − 44 × 0.5（交叉溶解）= **183.2 秒 = 3:03** |
| 每段耗时 | 本机 **131–158 秒**，远端 **146–148 秒** |
| 首帧每张 | **3.6–5.2 秒**（z_image_turbo） |
| 配音每句 | **约 18 秒**（IndexTTS-2.5，ComfyUI 侧计时） |
| 单向全片 | 45 × 145 ≈ **109 分钟**；双线对半 ≈ **55 分钟** |

**为什么是 73 帧而不是更长**：`length` 被完全尊重，但每帧耗时随长度上升
（49 帧 1.867 s/帧 → 121 帧 2.408 s/帧，涨 29%）。3 分钟片长在 49/73/97/121 帧
各方案下总耗时都收敛到 100–110 分钟，而 73 帧的 45 段规模最可控。

## 七、配音：音色挂在【角色】上

`音色\角色映射.json` —— 剧本里只写角色名，音色由这张表决定。
挂台词上的话，同一个角色十句台词要在十个地方写音色，改一次要改十处，**必然漏一处**。

**怎么挑音色**（比读元数据靠谱得多）：`音色库.json` 的元数据太稀
（1415 条里 967 条性别是空、1218 条年龄是空，筛「青年男」得 0 条），
但**文件名的信息量比字段大得多** —— `男-奸诈狡猾 老谋深算.wav` 这个名字本身就是选角说明。
`_选音色_磨刀.py` 就是按关键词找 + `soundfile` 真解码验（采样率/时长/RMS/峰值/削波）。

## 八、混音链（照抄）

```
各句 wav → adelay=<起>|<起> → amix=inputs=N:duration=longest:normalize=0  [人声]
棕噪 → highpass=180,lowpass=1400,volume=0.055                            [风/底噪]
[人声][风] amix=inputs=2:duration=first:normalize=0 → alimiter=limit=0.95,apad
-t <视频时长>    ← 用片子的实测时长，不是音频的
```

**⚠ 绝不能加 `-shortest`**：它会把**画面**裁到音频长度。
《试镜》那次成片从 23.56 秒被砍成 18.65 秒，最后三格直接没了，而且 ffmpeg 报成功。

**⚠ 产物后缀写 `.wav` 其实内容是 FLAC** —— 这个 ComfyUI 存不出真 WAV
（`comfy_extras\nodes_audio.py:159-185` 的 `SaveAudio` 是 `Save Audio (FLAC) (DEPRECATED)`，
`comfy_api\latest\_ui.py:259` 的 `_FORMATS = {"flac","mp3","opus"}`）。
ffmpeg 按魔数认，不用管后缀；要真 WAV 就走 `配音.转真WAV()`。

## 九、还没验的（诚实记的差）

- 阿七的军服漂移**没修好**（见第四节末）。
- 「两张一模一样的脸同框」（《雪线》的收尾设计）**没验过**；《磨刀》没用这个设计。
- 45 段是**双线混合**出的（本机 25 + 远端 20）——同一种子同一模板，
  但两条线的 GPU 相同型号才敢这么混，**换不同型号的卡没验过**。
- `_出片.py` 的段耗时会随机器负载波动（本机 131–158 秒，格25 那次异常到 313 秒），
  排期要留余量。
