# 音轨静默被砍断（amix / sidechaincompress 的「谁短跟谁」）

> 2026-10-14 在《觉醒》拼片时抓到。**所有日志全绿、音轨也在、`ffprobe` 显示正常，
> 但成片后半段是数字静音。** 属于[假判据族](假判据族.md)里「判据说 OK 但什么都没量」的第八种形状。

## 症状

H3 每一格都自带环境音（雨声、脚步、衣料）：

| 段 | mean_volume |
|---|---|
| `格1_本机.mp4` | **-40.9 dB** |
| `格2_本机.mp4` | -39.4 dB |
| `格3_本机.mp4` | -35.9 dB |

可是拼出来的片子：

```
Duration: 00:00:24.29   ← 时长对
Stream #0:1: Audio: aac (LC), 48000 Hz, stereo   ← 音轨在
（volume 一量）
mean_volume: -91.0 dB   ← 整条是数字静音
```

`ffprobe` 一切正常，**只有 `volumedetect` 能看出来**。

## 根因

ffmpeg 的 `amix` 和 `sidechaincompress` 都是**「谁短跟谁」**：

- `amix=inputs=N:duration=first` → 输出长度 = **第 1 条输入**的长度
- `sidechaincompress` → 输出长度 = main 与 sidechain 里**短的那条**

而人声是**有限长**的（最后一句台词说完就没了），片子是 31 秒。

于是这条链：

```
[人声]asplit=2[人声出][人声键];
[原声][人声键]sidechaincompress=...[原声压];     ← 被截到最后一句台词结束
[原声压][人声出][风]amix=inputs=3:duration=first  ← 又跟着截断
```

**第一句台词开始才有声音，最后一句台词说完整条音轨就断掉。**
实测：最后一句在 23.0 秒结束，**23.5 秒处两套链都是 -91 dB**，
而输入在这一点的真实音量是 **-40.1 dB**。

## 修法

**进 amix / sidechaincompress 之前，每一条流都先 `apad` 铺满整片。**

```ffmpeg
[人声]asplit=2[人声出0][人声键0];
[人声出0]apad=whole_dur=31.290[人声出];      ← 两条分支都要补
[人声键0]apad=whole_dur=31.290[人声键];
[原声][人声键]sidechaincompress=threshold=0.04:ratio=12:attack=15:release=450:makeup=1[原声压];
[原声压][人声出][风]amix=inputs=3:duration=first:normalize=0[混];
[混]alimiter=limit=0.95,apad[aout]
```

`anoisesrc` 产棕噪时也要写 `duration={总+5}`（比片子长），否则它自己也会成为短的那条。

**顺序也要对**：无原声的兜底链 `[人声][风]amix=duration=first` 要写成 `[风][人声]` ——
把无限长的那条放第 1 位。

## 判据（`_验混音_觉醒.py`）

同一条片子、同样几个窗口，比「留原声」和「丢原声」两套链：

```
窗口                      旧链(丢原声)      新链(留原声)
4.0s　没人说话              -51.8 dB        -44.9 dB     +6.9
6.6s　人声在说              -16.5 dB        -16.5 dB      0.0   ← 该一样就得一样
10.5s 没人说话             -52.0 dB        -39.0 dB    +13.0
13.6s 人声在说             -20.2 dB        -20.1 dB      0.0
18.0s 没人说话             -51.7 dB        -38.8 dB    +12.9
23.5s 没人说话             -52.1 dB        -36.5 dB    +15.6   ← 修好后这里不再静音

✓ 没人说话的窗口，新链比旧链响  +6.9 / +13.0 / +12.9 / +15.6 dB
✓ 人声窗口 -16.5 dB 比空窗 -36.5 dB 高 20.0 dB（台词盖得住环境）
```

**两条判据缺一不可**：只看「空窗更响了」会漏掉「人声被环境盖住」；
只看「人声够响」会漏掉「环境音全丢了」。**人声窗口两套链必须打平（0.0 dB）**，
这一条专治「改了 A 顺手把 B 也改了」。

## 顺带记住

`-shortest` **不能加**：它把画面裁到音频长度。
《磨刀》那次 23.56 秒的片子被砍成 18.65 秒。

# 第二件：台词被环境声埋掉（2026-10-14 晚，《觉醒》）

## 症状

成片能听，但**台词像是念白埋在雨里**。全片取点量：
```
  8s -33.2   40s -22.9   70s -30.0   150s -28.6   200s -39.6   260s -45.5   285s -22.3 dB
```
台词窗和「缝里的留白」只差 **2.9 dB**。

## 根因

`_配片.py` 的混音链里，**H3 的原生环境声和每一句人声都按 `volume=1.0` 并排进 amix**：

```python
链.append(f"[{idx}:a]adelay={毫}|{毫},volume=1.0[v{i}]")   # 每句人声 1.0
...
f";[0:a]aresample=48000,volume={参.原声量}[原声];"          # 原声也是 1.0
```

`amix=...:normalize=0` **不归一化**，就是直接相加。
于是**谁录得响谁就赢** —— 而 H3 的环境声本来就录得不轻。
侧链压缩只在「说话的那一瞬间」把环境压下去，
它管不了「人声本身就只有环境那么大」。

## 修法

**人声先提上来，再进侧链和她并列。**

```python
f"amix=inputs={len(段们)}:duration=longest:normalize=0[人声0];"
f"[人声0]volume={参.人声量}[人声]"          # ★ 这里最容易漏掉输入标签
```
- 新增 `--人声量`，默认 **2.6**（≈ +8.3 dB）
- `--原声量` 默认从 1.0 降到 **0.7**（≈ -3.1 dB）

**踩的坑**：第一次写成 `f"volume={参.人声量}[人声]"` ——
**漏了输入标签 `[人声0]`**，ffmpeg 报的是一句很难懂的
`Filter amix:default has an unconnected output`。
滤镜图里 `;` 之后的每一段都必须自己带输入标签，不会自动接上一段的输出。

## 判据（改完实测）

```
  台词窗 64 个  中位 -15.9 dB
  真空窗 71 个  中位 -34.9 dB
  → 分离度 +19.0 dB  ✓ 台词清楚压过环境音
```
从 **+2.9 dB** 提到 **+19.0 dB**。

**★ 留白窗怎么取才对**：必须**离任何一句字幕都 >= 0.6 秒**。
取「相邻两句之间的缝」是错的 —— 排轴改成「一句都不许往回挪」之后
缝只剩 0.20 秒，正好落在 `release=450ms` 里，量到的是环境音**还没放回来**的值。
（详见 [`假判据族.md`](假判据族.md) §3.5。）
