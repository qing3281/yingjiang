## 0. 一句话

飞彩这两个模块**没有后端秘密**：推文 = 「LLM 拆叙事合集 → LLM 出九宫格画面描述 → 文生图/图生图 → 图生视频 → 表格排期 → zip 导出」；
电商 = 「面板表（11 个）+ 每面板一段 systemPrompt + 一个 userInput 模板 → LLM 出提示词 → 批量出图/出片 → 归档 → 导出」。
影匠缺的从来不是算法，是**这套字段、文案和流程**。两个 `.py` 就是把它们按原样搬到影匠的命令行上。
