# 飞彩工作室 V2.53l（Mac 版）安装说明

## 〇、关于 DMG 与完整目录（重要须知）

- **完整目录是唯一可写交付入口**：程序运行和以后的软件内更新都发生在解压/复制出来的完整目录（或安装到本机的位置）里；请保留目录内全部文件，不要只把启动器单独拷走。
- 若你拿到的是 **DMG**：它只是**只读挂载**的分发载体。请把 DMG 窗口里的完整目录**复制**到磁盘上（例如桌面或「应用程序」文件夹）再使用，不要直接在挂载位置里运行。
- **不要在挂载（只读）位置内热更新**：软件内更新只写你磁盘上的完整目录，在 DMG 挂载位置内更新会失败。

## 一、安装：五步

**第 1 步 · 解压**
双击下载到的 `FEICAI-Studio-Mac-V2.53l.zip`，等它完全解压，得到文件夹 `FEICAI-Studio-Mac-V2.53l`。
> 不要在压缩包里直接双击运行，一定要先解压出来。

**第 2 步 · 双击启动器**
打开该文件夹，双击里面的「飞彩工作室-启动器.app」（带飞彩图标那个）。

> ⚠️ 不要双击 `start.command`：那是命令行窗口，容易被系统拦下，也不是正式入口。
> ⚠️ 在这一步之前，不要把「飞彩工作室-启动器.app」单独拖到别处——它要和文件夹里的程序文件在一起才能完成安装。

**第 3 步 · 第一次打开会被系统「隔离」一次，点「一键修复」**

这一步每个新下载的包都会有，**不是文件损坏**：

1. 界面上会出现一张卡片：**「macOS 把启动器隔离到了临时位置」**，并说明文件并没有损坏；
2. 点卡片上的 **「一键修复」**；
3. 在弹出的选择窗口里，选中**你解压出来的那个文件夹**（里面同时有「飞彩工作室-启动器.app」和一堆程序文件），点 **「修复并重新打开」**；
4. 启动器会自动清掉「来自网络」的标记，并从原来的位置重新打开。

> 只需做一次。装到本机之后，即使再被系统隔离也不影响使用。

**第 4 步 · 点「安装到本机」**

重开之后，窗口**左侧那一栏的最上面**会出现一张卡片：**「把程序安装到本机，之后这个文件夹可以删掉」**。
点卡片上的 **「安装到本机」**，等它跑完（通常几十秒，最慢 1–3 分钟）。

装好后卡片**会留在界面上**并显示：**「安装完成。重启启动器后即从本机运行，原文件夹随后可以删掉」**。

**然后请关掉启动器，再重新打开一次**——这一步不能省，在那之前程序仍从原文件夹运行。

**第 5 步 · 收尾**

第二次打开确认一切正常（能登录、能进入工作台）之后：

- 可以把「飞彩工作室-启动器.app」拖进「应用程序」文件夹（可选，推荐）；
- 下载解压出来的那个文件夹、以及下载的 zip，**这时候才可以删掉**。

> 📌 有一个文件夹请务必不要删：程序本体装在**你自己用户文件夹**里的 `Applications/FEICAI-Studio-Installations`。
> 在访达里按 **⇧⌘H**（回到个人文件夹）就能看到那个 `Applications`；删了它程序就打不开了。
> **要删的是「下载解压出来」的那个文件夹，不是它。**

> ✅ 装完之后，从**任何位置**打开启动器都行（解压文件夹里的、应用程序里的都可以）——启动器会自动从本机那一份运行。

## 二、首次安装会发生什么

| 你可能关心的 | 说明 |
| --- | --- |
| 会发生什么 | 把一份完整运行环境复制到你**自己的用户目录**里；**原文件夹一个字节都不会改动**，也不会覆盖或删除你已有的任何东西 |
| 需要多久 | 通常几十秒，最慢 1–3 分钟；过程中可以取消，取消后不留残留 |
| 占用多少磁盘 | 下载包约 560 MB，解压后约 1.2 GB；建议预留 3 GB 以上 |
| 装完必须做什么 | **关掉启动器再重新打开一次**；在那之前程序仍从原文件夹运行 |
| 为什么要装到本机 | 装完以后程序位置就固定了，移动或删除下载文件夹都不影响使用，以后升级也都在本机进行 |
| 需要联网吗 | 安装本身不需要联网 |
| 会改动我的项目/素材吗 | 不会。你的项目、素材、账号配置都在另外的位置 |

### 安装没成功怎么办

窗口里会直接写出原因，按提示处理即可：

| 界面提示 | 怎么处理 |
| --- | --- |
| 复制失败，请检查磁盘空间后重试 | 清理磁盘到 3 GB 以上可用，再点一次「安装到本机」 |
| 复制结果校验不通过，本次未启用 | 通常是磁盘或权限的临时问题：重新点一次即可；反复失败请联系技术支持 |
| 读不到版本号，请确认解压完整 | 说明解压不完整：删掉解压出来的文件夹，**重新解压一次**压缩包再试 |
| 当前位置的程序文件不完整，请先完整解压 | 请在**解压出来的文件夹里**双击启动器，不要在压缩包内直接打开 |
| 本机已有同名安装，但校验不通过；为安全起见没有改动它 | 程序为保护你已有的文件而停手。**请不要自行删除那个文件夹**，直接联系技术支持 |
| 本机安装位置不可用，暂时无法安装到本机 | 程序在你的用户目录下建不出安装位置。请确认「应用程序」目录能正常打开；仍然不行就点「获取更新」重新下载一次官方安装包 |
| 你的主目录不可写；请改用管理员账户或联系技术支持 | 常见于公司统一管理的电脑、只读磁盘或网络家目录。请改用有写权限的账户登录，或把这个提示发给技术支持 |
| 请把解压出来的文件夹移到桌面或「文稿」文件夹后，再点安装 | 你把压缩包解压到了程序自己的安装目录里面。把**整个文件夹**拖到桌面或「文稿」后，再双击里面的启动器点「安装到本机」 |
| 本机副本仍被系统隔离，安装未生效 | 这不是复制失败，也不影响你现在正用的那一份。请点上方「一键修复」后重试；仍然不行就把整个文件夹拖到「应用程序」再试 |
| 装到一半取消了 / 关掉了窗口 | 不会留下任何残留，重新点一次「安装到本机」即可 |

## 三、系统要求

- **macOS 13（Ventura）或更高**；
- Apple 芯片与 Intel 芯片都支持（同一个安装包里带了两套运行环境）；
- **不需要**自己安装 Node.js 或任何运行库，安装包已内置；
- 建议预留 **3 GB 以上**可用磁盘空间；
- 首次打开如果被系统拦下，请到「系统设置 → 隐私与安全性」里选择「仍要打开」；正常打开一次之后就不会再拦。

## 四、旧版本用户请手动装一次

**如果你现在用的是旧版本，这一版需要你手动下载安装一次**，装法与全新安装完全一样，就是第一节那五步。
原因：旧版启动器里的「获取更新」只是帮你打开下载页，它不会替你下载和安装。

安装新版时：**不需要**先卸载旧版、**不需要**删除旧版本所在的文件夹；装好新版、确认能正常使用之后，再自行清理旧文件夹即可。
**从这一版开始，后面的更新就能在设置页里正常进行了。**

遇到任何一步卡住，请把**启动器窗口里的文字**（截图最好，窗口里已经写明原因与建议）发给技术支持。
