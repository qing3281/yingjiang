# 动态提示词

> 图生视频里，**决定成败的不是画质，是「动什么」和「怎么动」**。
> 一张好图 + 一个坏动作 = 废片。一张普通图 + 一个好动作 = 能用。

---

## 一、核心矛盾：AI 想动一切，你只想让它动一样

把一张图丢给视频模型，它会**默认让所有东西都动**：头发飘、衣服摆、云在走、背景在晃、脸也在变。

结果就是「果冻感」——画面很忙，但什么都没讲清楚，而且**脸崩了**。

**所以动态提示词的第一原则是限制，不是添加。**

```
❌ 让画面动起来                      ← 什么都没说，AI 乱动
✅ 她的头发被风吹动，其余保持静止      ← 指定 + 限制
```

## 二、五种基本运动

### 2.1 主体运动（角色做什么）

**写法：动词开头，一句话，正在进行的时态。**

| 想要 | 提示词 |
|---|---|
| 转头 | `she slowly turns her head to look at the camera` |
| 拔剑 | `he draws the sword from its sheath in one smooth motion` |
| 走 | `she walks forward at a steady pace` |
| 抬手 | `she raises her hand and touches her hair` |
| 睁眼 | `she slowly opens her eyes` |
| 微笑 | `a faint smile forms on her lips` |

**关键**：
- **加 `slowly` / `gently` / `gradually`** —— 不加就快得像抽搐
- **一个镜头一个主动作**。想让她「转头 + 抬手 + 说话」＝ 崩脸
- **用 `begins to` / `starts to`** 可以只做动作的前半段，留悬念且更稳

### 2.2 摄影机运动

| 运动 | 提示词 | 效果 |
|---|---|---|
| 推 | `slow push in, dolly in` | 注意力收拢、情绪加压 |
| 拉 | `slow pull back, dolly out` | 揭示环境、孤立感 |
| 摇 | `pan left / pan right` | 扫视、跟随 |
| 移 | `tracking shot following the subject` | 陪伴感 |
| 升 | `crane up, rising camera` | 拉开、收尾 |
| 降 | `crane down, descending camera` | 逼近、压迫 |
| 环绕 | `orbit around the subject, arc shot` | 展示、仪式感 |
| 手持 | `handheld camera, slight shake` | 纪实、紧张 |
| 固定 | `static camera, locked off` | 冷静、观察 |

**摄影机运动 + 主体运动不要同时要**。两个都在动，AI 会算不过来，画面糊。
要么主体动、机器静；要么机器动、主体静。

### 2.3 环境运动

这是**让画面「活」而不用主角冒险**的最安全手段：

| 环境 | 提示词 |
|---|---|
| 头发 | `hair swaying gently in the wind` |
| 衣摆 | `the hem of her robe flutters in the breeze` |
| 雪 | `snowflakes drifting down slowly` |
| 雨 | `rain falling, ripples on the ground` |
| 烟 | `smoke curling upward` |
| 水 | `water surface rippling` |
| 云 | `clouds drifting slowly across the sky` |
| 火 | `fire flickering, embers floating up` |
| 尘 | `dust motes floating in the light beam` |
| 草 | `grass swaying in the wind` |

**用法**：主体完全静止 + 环境在动 = 一张「活的画」。**这是最稳、最不容易崩的做法**，适合气氛镜、开场、结尾。

### 2.4 光线运动

`light shifting across the face` / `shadows moving slowly` / `a beam of light sweeping past`

效果是「时间在流逝」，适合过渡镜。

### 2.5 焦点运动

`focus racks from the foreground to her face` / `shallow depth of field, background blurring`

**变焦跟焦**是专业感的捷径 —— 大部分 AI 视频都没有焦点变化，一有就显得高级。

## 三、运动强度分级

不同镜头想要的「动」不一样。写之前先定级：

| 级别 | 描述 | 提示词 | 用在哪 |
|---|---|---|---|
| 0 | 几乎静止 | `almost still, only subtle breathing motion` | 端详、凝视、仪式 |
| 1 | 微动 | `gentle hair movement, subtle breathing` | 特写、对话 |
| 2 | 常速 | `she turns and walks toward the camera` | 叙事主力 |
| 3 | 剧烈 | `she spins around, robes billowing dramatically` | 打斗、爆发 |
| 4 | 极端 | `explosive motion, debris flying` | 高潮 |

**全片不要一直 3–4。** 分级的意义就是有对比。全片都在动 = 观众麻木。

## 四、时长的门道

一个镜头要几秒，取决于**这个动作需要多久才看得清**：

| 动作 | 最短可读时长 |
|---|---|
| 睁眼 / 微笑 | 1–2 秒 |
| 转头 | 2–3 秒 |
| 抬手 | 2–3 秒 |
| 起身 | 3–4 秒 |
| 走几步 | 4–6 秒 |
| 拔剑 + 挥砍 | 4–5 秒 |
| 环绕一圈 | 6–8 秒 |

**写提示词时要和时长相配**：
- 3 秒的镜头写「她走过去拔剑挥砍」＝ 一定糊
- 8 秒的镜头只写「她睁眼」＝ 后面 6 秒 AI 自己发挥，多半乱动

**做法**：先定时长，再倒推写多长的动作。或者反过来——**动作写完，按上表定时长**。

## 五、提示词模板

按这个骨架填，不会漏东西：

```
[主体 + 原始外貌锚点]，
[一个主动作，带副词控制速度]，
[环境运动，1–2 项]，
[摄影机运动 或 static camera]，
[光线变化（可选）]，
[运动强度词]
```

实例：

```
凌霜，银白长发披肩，紫色杏眼，黑色修身长袍银色云纹刺绣，
she slowly turns her head to look directly at the camera，
hair and robe hem swaying gently in the wind，
static camera，slow subtle motion，cinematic
```

**顺序讲道理**：
1. **主体外貌锚定在最前** —— 让模型先抓住「这是谁」，后面动起来才不容易换脸
2. **动作紧跟** —— 这是要发生的事
3. **环境补充** —— 让画面不呆
4. **机器指示** —— 防止模型自作主张地推拉
5. **强度收尾** —— 全局降速

## 六、保脸：让主角别变形的所有手段

AI 视频里最痛的是**脸崩**。成因和破解：

| 崩脸的原因 | 破解 |
|---|---|
| 动作太大太快 | 加 `slowly`，降一档运动强度 |
| 头部大幅转动 | 改成小幅转动 / 只动眼睛 |
| 同时多个动作 | 砍到一个 |
| 机器也在动 | 改 `static camera` |
| 参考图脸部占比太小 | 用更近的景别做首帧 |
| 时长太长 | 缩短，或让动作只做前半段 |

**最稳的三种镜头**（脸几乎不崩）：
1. **环境动、人不动** —— `hair swaying, snow falling, static camera`
2. **机器动、人不动** —— `slow push in on her face, she remains still`
3. **极小动作** —— `she blinks slowly, a single tear rolls down`

**要冒险的镜头**（可以崩，多生成几版挑）：
- 打斗、奔跑、转身、大幅度手势、多人互动

**策略**：一场戏里，**保脸镜和冒险镜交替**。冒险镜崩了就换成保脸镜顶上，不影响成片。

## 七、首帧的选择决定上限

图生视频的第一帧**几乎决定了整个片段的质量上限**。

### 7.1 首帧要满足的条件

- [ ] **主体清晰**，脸够大（至少中景以上）
- [ ] **姿态有「动势」** —— 身体朝某个方向倾、手抬到一半、衣摆飘起来
- [ ] **不遮挡关键部位** —— 手别挡脸，头发别糊住眼睛
- [ ] **背景不过于杂乱** —— 否则模型会把背景也动起来
- [ ] **光线明确** —— 顺光/逆光清晰，模型才知道怎么动阴影

### 7.2 从静图反推动作

看一张首帧图，问：**「这张图看起来下一秒会发生什么？」**

- 图里她微微侧身看向远处 → 动作是「她转过来面向镜头」
- 图里她手按在剑柄上 → 动作是「拔剑」
- 图里她嘴唇微启 → 动作是「说话」或「叹气」
- 图里风吹起头发 → 动作是「风继续吹，头发飘得更开」

**顺着图的「势」写动作，成功率最高。**逆着图的姿态硬拗动作，一定崩。

### 7.3 首帧生成时就为动态做准备

生首帧图的时候，提示词里**就带上将来的动作暗示**：

```
凌霜侧身站立，手按在剑柄上，身体重心前倾，衣摆被风吹起 ——
（生图时）
```

图里已经有「势」，视频阶段只要 `she draws the sword`，成功率远高于从一张笔直站立的图开始。

## 八、音画同步（做配音时的注意事项）

如果镜头里有人说话：

| 要点 | 做法 |
|---|---|
| 口型 | AI 口型对不上是常态。**用侧脸、背身、或嘴部被遮挡的构图规避** |
| 语速与时长 | 台词 4 秒 → 镜头至少 5 秒，留出入画和收尾 |
| 呼吸 | 长台词前留半秒吸气，能显著提升真实感 |
| 情绪 | 配音的情绪要跟画面光线一致（暖光配温柔，冷光配冷硬） |

**最省事的办法：旁白 + 无口型画面。** 观众接受度极高，且完全避开对口型的坑。

## 九、自检清单

一个动态提示词写完，逐条过：

- [ ] 有且只有**一个**主动作？
- [ ] 加了速度控制词（`slowly` / `gently`）？
- [ ] 主体外貌锚点写在最前面？
- [ ] 环境和机器的运动**没有和主体抢戏**？
- [ ] 写明了 `static camera` 或明确的机器运动？
- [ ] 动作的长度和镜头时长匹配？
- [ ] 这个镜头是「保脸」型还是「冒险」型？冒险的有备份方案吗？
- [ ] 首帧的「势」和要写的动作方向一致吗？

## 十、常见错误对照

| 错误 | 结果 | 改法 |
|---|---|---|
| 「让画面动起来」 | 全屏果冻 | 指定一个动作 |
| 同时三个动作 | 脸崩 | 砍到一个 |
| 没写速度词 | 快进感 | 加 `slowly` |
| 机器和主体都在动 | 画面糊 | 二选一 |
| 动作比时长长 | 最后几帧崩坏 | 缩短动作或加时长 |
| 动作比时长短 | 后半段 AI 自由发挥 | 加环境运动填满 |
| 首帧没动势 | 动起来僵硬 | 重生首帧，加动势 |
| 全片都是剧烈运动 | 观众麻木 | 按强度分级排布 |
| 忘了写 `static camera` | 模型自己推拉 | 显式写死 |
