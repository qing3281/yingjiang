## 二、怎么挂

```python
import 导演
导演.让镜动(镜头果, 动作描述, 模板="minimax_h3_i2v",
           角色LoRA="H3_Combat_V2.safetensors", LoRA强度=1.0)
```

引擎里的 `_挂角色LoRA()` 认「末端 LoRA」——**不写死节点号**（四个模板的 LoRA 编号分别是
121/121/145/无）。模板里一个 LoRA 节点都没有时（`wan22_i2v` 就是），它回退到主模型
（`UNETLoader` / `CheckpointLoaderSimple`）再接。

**挂不上不报错，只是不生效** —— 最难发现的那种错。所以引擎每次都回一行
「挂上角色 LoRA：X（强度 N，接在 121 后面）」，看到这行才算真的挂上了。

## 三、★ 实测结论：LoRA 不是「打斗开关」

2026-10-15 跑了一组对照。同一张首帧、同一句提示词、同一个种子 `576185390`：

| | 挂 `H3_Combat_V2` | 不挂（对照） |
|---|---|---|
| 出片耗时 | 75.1 秒 | 64.6 秒 |
| 画面 | 框架收得更紧、镜头自己推近、最后一帧是极近特写、表情更狠 | 保留更宽的巷子景、推得少 |
| 会不会打 | **会** | **也会** |
| 成品 | `作品\打斗_挂Combat_00001_.mp4` | `作品\打斗_不挂_00001_.mp4` |
| 对照图 | `作品\_动作试验\挂与不挂_对照.png` | 同上 |

**结论：H3 底模本来就打得好。LoRA 改的是「框架和劲道」，不是「会不会打」。**

那什么才是关键？**提示词里有没有写动作。**
原来的分镜提示词只描述画面（穿什么、在哪、什么光），模型就只能给你一张
**会呼吸的照片** —— 这就是 `一镜里像看图片.md` 那个老毛病在视频这一层的版本。

所以风格库加了「动作」字段和 `动=True`：

```python
风格库.编译("kungfu-duel", 动=True)   # → 正向里多一句 631 字符的动作描述
风格库.编译("kungfu-duel")            # → 390 字符，只有画面
```

## 四、四个动作风格（2026-10-15 加，风格库 28 → 32）

| 键 | 中文 | 该挂的 LoRA | 动作句写的是什么 |
|---|---|---|---|
| `kungfu-duel` | 武侠对招 | `H3_Combat_V2` | 拳头打穿、躯干硬转、袖子和头发跟着甩、收势回架 |
| `gunfight` | 枪战 | `GunFu` | 抬枪开火、后坐力顶肩、枪口闪频闪、换掩体再起身、弹壳在空中翻 |
| `chase` | 追逐 | `wushu_spatial_physics_v2` | 全力冲刺、手臂摆动、脚掌重踏、身体前倾、回头看不减速 |
| `brawl` | 近身肉搏 | `H3_Combat_V2` | 撞在一起、短勾拳打中、头被打偏、抓衣领顶膝、镜头跟着每次撞击抖 |

`风格库.动作类()` 只列这四个；`风格库.配LoRA(键)` 直接告诉你该挂哪个。

**注意**：这四个风格的建议是「出视频用」。出**图**的时候 `动=False`（默认就是 False），
不然会把一句动作描述塞进静态图的提示词，模型可能给你画出一张「打了一半」的怪姿势。
