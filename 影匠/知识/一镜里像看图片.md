# 一镜里像看图片 —— 根因是首帧把动作演完了

> 用户先后说过两次：「单镜里像看图片」「动作不连贯、前后衔接有问题」。
> 换 MiniMax-H3 之前，这被归咎于 `wan2.2_ti2v_5B` 是个 5B 小模型、只会做很轻的运动。
> **换了大模型之后问题还在** —— 说明根因不在模型。

## 一、先量，别猜

`D:\DSHworkspace\影匠\_量运动.py`：逐帧算相邻帧灰度差的平均，对整格取平均。

```bash
python 工具\_量运动.py 觉醒              # 量 段\ 全部
python 工具\_量运动.py 觉醒 --只格 42     # 只量几格
```

全片 74 格实测：

| | 值 |
|---|---|
| 最小 | **0.450** |
| 中位 | 1.278 |
| 最大 | 7.086 |
| 平均 | 1.595 |
| 冻死（<0.2） | **0 格** |
| <0.6 | 5 格（7%） |
| <1.0 | 26 格（35%） |

**没有一格是冻住的。** 所以「像看图片」不是「完全不动」——
是「**该动的地方没动**」。这个区别决定了后面所有判断。

★ 这个数只能筛出**异常安静**的格子，**不能**当「动得好」的证据：
噪点、压缩抖动、光影晃都会让它变大。要判动作对不对，还得看图。

## 二、看图才看见真因

把最静的 16 格各取 0.2s / 2.2s / 4.2s 拼成 `作品\觉醒\_最静16格_首中尾.png`，一眼看出：

- **格5**（手写册子）：三个时刻姿势**完全一样**，笔悬在纸上就是不落下去
- **格42**（六根指头）：三个时刻都是**五指张开**的同一张
- **格49**（有人看见了）：水瓢已经滴着水、扁担还在肩上 —— 三个时刻一样

再去看这三格的**分镜原文**，根因就露出来了：

```
格42 动作：他把手抬起来看，手指一根一根分开又合上，手在很轻地抖
格42 提示词：…手在很轻地抖，抖的幅度很小，指头一根一根地分开又合上。…
                        ↑ 首帧提示词里写着动作**正在做**
格49 提示词：…两个穿灰麻短褂的年轻杂役都停下手里的活站着：一个手里还捏着一只木瓢、
              瓢沿往下滴水，另一个肩上扛着一根扁担…       ↑ 已经是「停下手」之后的状态
```

### ★ 根因

`02-九宫格.md` 里 **`提示词` 这一个字段被两个步骤共用**：

| 谁用 | 怎么用 |
|---|---|
| `_出片.py:97` | `词 = f"{景}。{格['提示词']}，{尾}"` —— 拿去出**首帧静图** |
| `_出H3.py` | 用 **`动作`** + `光色` 拼视频提示词 |

为了出一张「好看的静图」，`提示词` 天然会写成**动作做到一半/做完**的样子
（张开的手比并拢的手更像一张海报）。于是首帧交到 H3 手上时，
**动作已经演完了** —— H3 锚定这张图，没有理由再动。

**这是流程设计的毛病，不是模型能力不够。**

## 三、改法：首帧只画「动作还没开始」

### 实验（格42，同一个六指手）

把 `提示词` 里那句改成动作**开始前**的状态：

```
旧：手在很轻地抖，抖的幅度很小，指头一根一根地分开又合上。
新：五根手指并拢在一起、还没有分开，指尖微微蜷着，手悬在胸前正要开始动。
```

重新出首帧（`_出片.py 觉醒 --图 --只格 42`），再出视频，量出来：

| 版本 | 运动量 |
|---|---|
| 原生产（张开首帧 · I2VA） | 0.461 |
| **对照（并拢首帧 · I2VA）** | **0.718** |
| FL2VA（并拢首帧 + 张开末帧） | 0.907 |

看图（`作品\觉醒\_格42_三版对比.png`）：

- **并拢首帧 · I2VA**：0.2s 并拢 → 2.2s 正在张开 → 4.2s 张开。**动作完整、渐进。**
- FL2VA：0.2s 并拢 → **2.2s 就已经张开** → 之后保持。动作被挤到前半段。

### ★ 结论：不要用末帧，改提示词就够

只改首帧提示词，运动量 0.461 → 0.718，**且动作分布最均匀**。
FL2VA 更高一点（0.907）但要**每格多出一张图**，而且动作挤在前半段。

**代价对比**：改提示词 = 零额外算力；FL2VA = 74 张额外静图（约 74×6 秒）。

## 四、写成规矩

> **`提示词` 字段描述的是这一格「开拍那一刻」的画面 —— 动作必须还没发生，或者刚刚起头。
> 动作的过程写进 `动作` 字段，不要写进 `提示词`。**

自查一句话：**把 `提示词` 交给画师画成一张静图，这张图应该是动作的「起手式」，不是「定格」。**

反例（本项目实际踩的）：
- 「指头一根一根地分开又合上」→ 画出来是五指张开 → ✗
- 「两个杂役都停下手里的活站着」→ 画出来是已经停下 → ✗
- 「他把话说完，抬起来的右手往院子那边比了一下」→ 画出来是手已经比出去 → ✗

正例：
- 「五根手指并拢在一起、还没有分开，手悬在胸前正要开始动」→ ✓
- 「两个杂役直起腰、手停在半空，正要放下手里的活」→ ✓

## 五、生成后的闸门

改完提示词不等于每格都成。**出完片要过一遍量运动**：

```bash
python 工具\_量运动.py 觉醒
```

- 有明确动作、运动量却 **< 0.6** 的格子 → 回查它的 `提示词` 是不是又写成定格了
- 这条闸门**只能筛异常**，判「动得好不好」仍然要人眼看首中尾拼图

### 对症的解法（已接好线，未验证）

`_出H3.py --末帧目录` 已经能把 `last_frame` 接进工作流。用来治衔接有两种用法：

1. **接力**：第 N 格末帧 → 第 N+1 格首帧。两格之间**必然**接得上，
   不用靠 `转场吃 0.5` 去遮。代价是镜头变成了一镜到底，丢掉剪辑节奏。
2. **同场戏里「换景别不换空间」**（推荐）：第 N+1 格的首帧不用 `_出片.py` 重画，
   而是拿第 N 格末帧走 **Qwen-Image-Edit** 改景别 ——
   空间、光、人物位置都继承，只有取景框变了。
   这正是真人剧组换机位的做法。本项目已有 Qwen-Image-Edit 的接线（见 `知识\锁脸.md`）。

★ 注意 `知识\锁脸.md` 的教训：Qwen-Image-Edit 会把**构图**也锁进条件，
所以改景别时不能只写「extreme wide shot」——得明确说「把镜头往后退 / 靠近」。

## ★ 否定结果（2026-10-15 06:30）：那句英文尾巴**不是**压住动作的元凶

### 怀疑从哪来

`_出H3.py:189` 送给模型的整句话是：

```
{动作}。环境：{光色}。A continuous cinematic shot. Preserve facial identity and
natural skin texture. Keep the same person, the same clothing and the same location
as the reference image. Natural ambient sound matching the scene; no dialogue.
```

中文那段在说「做什么」，**英文那段从第一个字到最后一个字都在说「保持不变」** ——
Preserve 身份、Preserve 皮肤、Keep 同一个人、Keep 同一件衣服、Keep 同一个地点。
一个字都没让模型动。而全片 64% 的格子去噪运动量 < 0.6，很容易怀疑就是它压住的。

### 怎么做的 A/B

给 `_出H3.py` 加了 `--词尾 {原,动}`（备份 `_出H3.py.bak-词尾前`）。
`动` 版把那句换成：

```
One single continuous take. The movement described above happens visibly and gradually,
starting in the first second and finishing by the last; the pose at the end of the clip
is clearly different from the pose at the start. Keep the same person, the same clothing
and the same location as the reference image, and preserve facial identity and natural
skin texture. Natural ambient sound matching the scene; no dialogue.
```

**同一首帧、同一种子、同一端点（远端）、同一天连跑两组**，只差这一句。跑了格 9 / 42 / 44。

### 结果：**0.90×，反而更差**

| 格 | 现状 | 对照组（原词尾） | 试验组（动词尾） | 试验/对照 |
|---|---|---|---|---|
| 9 | 0.246 | 0.253 | 0.264 | 1.04× |
| 42 | 0.265 | 0.211 | 0.253 | 1.20× |
| 44 | 0.439 | 0.439 | 0.294 | **0.67×** |
| 平均 | — | 0.301 | 0.270 | **0.90×** |

### 两个结论

1. **英文词尾不是元凶。** 把「保持不变」换成「首尾姿势必须明显不同」，运动量没有系统性提升，
   在格44 上还掉了三分之一。**这条路关掉，以后不用再试。**
2. **★ 尺子是稳的。** 对照组跟「现状」（同一格、早先出的那一版，种子公式相同）
   差得很小：格9 0.253 vs 0.246、格44 0.439 vs 0.439、格42 0.211 vs 0.265。
   **同种子重跑的波动大约 ±15%** —— 所以 1.2× 以下的「提升」本来就在噪声里，
   以后报数必须说清楚这一条。

### 那到底什么管用

按目前全部实测，**只有一样东西管用：换首帧**（起手式），平均 1.3–1.4×，而且只对
「首帧画成了动作终点」这一种错有效。剩下的格子（模型自己就不爱动的）目前没有找到便宜的解法。
**没找到就是没找到 —— 不要拿「改了提示词」当成「问题解决了」。**
