# 锁脸（参考图锁角色）—— 做过的实验与结论

> 写作规矩：每一条都标「实测」还是「推断」。
> 没实测的一律进最后一节，不许写进正文当结论。

## 结论先行

**Qwen-Image-Edit-2511 能锁脸，但只在「不需要变构图」的场合能用。**
九宫格这种一格一个景别的分镜，用它会**把九个格全画成同一个中景胸像**（实测，四次复现）。

影匠现在的做法是对的，也是唯一有效的：

| 用途 | 用什么 |
|---|---|
| 九宫格 / 分镜（景别必须变） | **纯文生图 + 角色卡 + 固定种子**。实测九格脸一致、景别递进成立 |
| 海报 / 定妆照（构图本来就固定） | **Qwen-Image-Edit + 定妆照参考图**。实测 51.3 秒出 `作品\海报_凌霜.png`，脸与角色卡逐项对得上 |

## 做过的四组实验（全部实测）

### 实验一：本机没有编辑模型时的样子

纯文生图模型 `qwen_image_2512_fp8_e4m3fn` 配 `TextEncodeQwenImageEditPlus` 喂参考图
→ 832×1216、94.4 秒、**满屏黑白棋盘格伪影**。
摘掉参考图、其余参数不动 → 42.7 秒、完全干净。
**归因：模型没训练过参考图隐变量。** 这就是后来加 `_规格.要求` 硬校验的起因。

### 实验二：定妆照当底图，要求改景别（错的方向）

以凌霜定妆照（胸像）为参考图，提示词写 `extreme wide shot` 等不同景别，
跑 `python 剧组.py 出图 试镜` 重出九格：

```
▶ 出图收工：成功 9　跳过 0　失败 0　⏱ 合计 5.3 分（319 秒）
```

每格 ~35.2 秒（带参考图比不带的 3.6 秒慢十倍）。
**结果：九张全是中景胸像，景别全塌。** 格1 该看不见脸、格7 该是极特写，实际一模一样。
**归因：Qwen-Image-Edit 保留输入构图，只按提示词做修改；编辑模型不做重新构图。**

### 实验三：双喂（定妆照管脸 + 旧格管构图）

向 `TextEncodeQwenImageEditPlus` 的 image1/image2 双槽分别喂 定妆照 + 旧格：

| 试法 | 参考图顺序 | 要求 | 结果 |
|---|---|---|---|
| V1 | 定妆照 + 旧格1 | extreme wide shot | 灰底**抠图飘人**，最差 |
| V2 | 旧格1 + 定妆照 | 保持构图 | 变成 1024 方图胸像，构图没了 |
| V3 | 旧格7 + 定妆照 | 保持极特写 | 仍是胸像 |

**全部失败。**

### 实验四：换脸方向（以格N原图为底，只换脸）

`D:\DSHworkspace\影匠\_换脸试.py` —— 底图 = 该格自己的原图，参考图 = 定妆照，
提示词明确写「构图/景别/姿态/机位/光影/背景完全不变，只换脸」：

```
格7  ✓ 换脸_格7.png  655 KB  64.3 秒  挂2张
格1  ✓ 换脸_格1.png  840 KB  60.5 秒  挂2张
```

**结果：构图照样塌。** 格7 的极特写变成中景，格1 的远景变成中景，
两张都成了胸像，而且色调被参考图带偏（格1 整张发蓝）。

**这是第四次复现同一个现象** —— 结论可以定死了：
**只要参考图里有一张人像定妆照，Qwen-Image-Edit 的输出构图就会向它收敛。**

## 正确的用法：以图生图做「精修」，不做「重画」

飞彩自己的定位也是这个 —— 超分那套提示词里逐字写着
`This is NOT image regeneration. Do NOT redraw or reimagine` + `PIXEL-PERFECT copy`。
它把原图当参考图喂回同一个图像模型，而不是让模型重新画。

所以影匠的用法应该是：

1. **先纯文生图出构图正确的图**（无参考图，3.6 秒一格，景别由提示词决定）
2. **要精修再拿编辑模型以「原图 + 定妆照」过一遍** —— 此时可以接受构图微调
3. **海报 / 定妆照** 直接用编辑模型，反正构图本来就固定

## 没实测的（不许当结论用）

- 换 `bf16` 全精度主模型（38 GB）会不会改善构图跟随 —— **没下、没测**
- `TextEncodeQwenImageEditPlus` 里 image1/image2/image3 到底哪个槽是结构主导 ——
  **只试过两种顺序，样本太小**，`引擎.文生图` 内部是「按 id 排序填进 LoadNode 槽」，
  实际哪个文件进了哪个槽**没有逐次打印核对过**
- 换成 `qwen_image_edit_2509` 或 `fp8mixed` 会不会不一样 —— **没测**
- 用全身定妆照代替胸像定妆照会不会让景别正常 —— **没测**（推断会有改善，但没证据）

## 2026-10-15 07:35 ★ 定妆照：否定写法会把要避的东西召唤出来（陈老根的眼睛与围裙）

**做了两件事**：给《雪线》《磨刀》补出 7 张定妆照（雪线 2 张／磨刀 5 张，各 3.6–6.1 秒一张，
本机 RTX 5080），再把三部戏 11 个角色拼成 `作品\_定妆照总表.png`。

**★ 踩到的坑（两个，同一个病）**：
《觉醒》的陈老根那张定妆照上，锚点里写的
「眼窝深陷，**眼下两片青黑的眼袋**」被模型画成了**两块黑眼圈妆** ——
在影棚平光正面像这种拍法下，那行字被读成了「化黑眼圈的妆」而不是「老年人的眼袋」。
同一张图里，锚点明写「补了几十块灰布的旧布围裙（**颜色是灰的，绝不是白色**）」，
模型照样画成**米白色的干净围裙**。

**改法**：把「是什么」写足，把「不是什么」删掉 ——
- 「眼下两片青黑的眼袋」→「眼下的皮肤松弛、**颜色比周围略深一点、是老年人自然的暗沉**，
  两只眼睛周围干干净净、**没有化妆、没有黑眼圈、没有涂黑**」
- 「围裙（颜色是灰的，绝不是白色）」→「**一条中灰色粗布围裙**，布面洗得发旧发暗，
  上面横七竖八补着几十块深浅不一的**灰色补丁**」
- 顺手加一句「竹签是发黄的旧竹色，不是金属，不是发簪」（原来出来的是金色发簪）

重出：4.9 秒，黑眼圈没了、围裙是灰的。新旧对照 `作品\觉醒\_定妆照\_陈老根_新旧.png`。

**判据**：
1. 「A，绝不是 B」这种写法对模型等于没说 —— **要描述它是什么，不要描述它不是什么**
   （这条跟 `假字幕.md` 的「别在提示词里提『字幕』这个词」是同一个病）。
2. **同一段锚点，在「影棚平光正面像」下和在「影视剧照」下的渲染结果不一样** ——
   出定妆照时要把会在正面光下被读歪的说法改写，
   **但不要动 `01-节拍拆解.md` 的锚点原文**（那份喂给每一格首帧，一改就得重跑全片）。
   `影匠\_出定妆照.py` 里为此加了一张 `改词` 表：只影响定妆照。
3. **定妆照的「定位」那一行必须从锚点表里读，不许手写。** 我第一版凭记忆手写，
   把沈砚写成「学徒」（原文：磨刀匠 · 十年前听雪楼最年轻的刀客）、
   赵崇武写成「刀坊主人」（原文：提刑按察使司按察使）、
   阿七/阿满写成「刀坊伙计」（原文：参将 · 真叛徒／偏院茶铺烧火的 · 活人证）、
   周泰写成「对头」（原文：按察司的打手头目）—— 五个错四个。
   **凡是「从别处抄一行字」的地方，就真去读那个文件。**

### 补记：阿棠（2026-10-15 07:50）

同一天同一张表里第二个中招的：锚点写「头发在**两边各**盘成一个小髻、用**两根**削尖的竹签别住」，
第一版定妆照出的是**头顶一个丸子头 + 一根金色发簪**。

**病根是同一个**：位置（「两边」）和数量（「两根」）说得不够死，模型就按它见过最多的古装发型套。
改法也同形 —— 把位置和数量都写死：
「头发在头顶两侧各盘成一个小圆髻，是**两个**并排的小髻、不是头顶一个丸子头，
两个小髻分别在左耳上方和右耳上方；每个小髻里各横插一根削尖的竹签，一共**两根**竹签，
竹签是发黄的旧竹色、木头质感，不是金属，不是发簪，不是金钗」。
改完 4.9 秒出图，**两个小髻 + 两根竹签都对**。

**★ 一个要点**：`01-节拍拆解.md` 的那行锚点**我一个字没动**。
定妆照的改写只活在 `影匠\_出定妆照.py` 的 `改词` 表里 ——
那份锚点是喂给全片每一格首帧的，动它就得重出全片。
**所以「定妆照比成片更贴锚点」这件事是会发生的**，交付时要说清楚是哪一份跟锚点一致。
