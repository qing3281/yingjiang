### 根因（这条挺意外的）

MemSearch 配的是 `summarizeMode=dsh-headless`，要调 `dsh` CLI 去读会话存档。
Windows 上 `dsh` **只以 `dsh.cmd` 提供**，而 Node 出于 **CVE-2024-27980**
拒绝在没有 shell 的情况下 `spawn` 一个 `.cmd`：

```
实测：THREW: EINVAL spawn EINVAL
```

### 修法

1. **用 PyInstaller 造出真正的 `dsh.exe` 转发器**，装机 3 处。
   实测：MemSearch 现在能写出**真实正文摘要**（10-14 那份从 1,570 B 长到 9,307 B，
   尾部几条是真正的内容，不再是那句占位）。
2. **Hindsight 干净禁用**（本机确实没有任何 token，留着只会每会话刷 401）：
   `coding-agent.json` 里 `disabled: true`。
3. **建了零依赖的兜底文件 [`接续.md`](接续.md)**（23,578 B / 212 行）——
   内容全部从真实会话存档提取，**不依赖任何插件**。
4. **建了 [`AGENTS.md`](AGENTS.md)**（工作区根目录）——
   这个是关键：DSH 会自动读它，所以它能把「先读 `接续.md`」这条规矩**真的送到**下一个会话里。
   建完立刻生效（系统当场把它注入了我的上下文）。

### 还没修的（诚实记）

MemSearch 的**语义检索**要 `memsearch` CLI + 一个 Milvus 向量服务。
这台机器：**没有 `uv` / `uvx` / `pipx`**，19530 / 9091 / 8000 端口**都没开**。

**但不影响用** —— 记忆就是纯 markdown，`grep`/`read` 直接就能查。
`AGENTS.md` 里已经把「第 2 步：grep 记忆文件」写成固定动作。

### 我从这次的真正教训

> **写入修好了不等于不会再忘。** 之前忘事的结构性原因是：
> `D:\DSHworkspace\` 下**没有任何一个 DSH 会自动读的文件** ——

> 记忆写进了 `.memsearch`，但**没有任何东西强制去读它**。

赵崇武解开官袍领口 —— 左胸上有一道一模一样的旧疤：**当年行刑的人，就是他**。

### 3.4 双线是怎么做到「远端只给算力」的

用户的要求：「你怎么保证另一台机器只是提供算力，产出的质量和本机是完全一样的……
让那边只是提供一个视频生成的算力，但决定各种效果的，生成视频是什么样的，还得由这边来。」

**做法**：远端和本机跑的是**同一份代码、同一份模板、同一组种子、同一批模型字节数**，
区别只有 `引擎.换端点('远端')` 一行。

**证伪式验证**（`_双线端到端.py`，退出码 0）：

```
L1 模型一致    ✓ 通过   wan22_i2v 三件字节数两边相等
L2 工作流一致  ✓ 通过   本机发出指纹 == 对端执行指纹
L3 成片一致    ✓ 通过   832×480  16.0fps  3.06 秒  610,036 B
```

L2 比的是**逐节点、逐字段的工作流图**，不是「看起来差不多」——
是本机发出去的 JSON 和远端 `/history` 里存回来的 JSON 做了规范化后逐项相等。

### 3.7 字幕

**硬字幕**（烧进画面），不是软字幕轨 ——
软字幕在**微信 / QQ / 手机相册里默认不显示**，用户会以为没做。

`D:\DSHworkspace\影匠\_烧字幕.py`：

- 路径要转义 `\` → `/`、`:` → `\:`、`'` → `\'`（不转义会被 filter 语法当成参数分隔）

## 四、这一轮最值钱的几条通用教训

### 4.1 「假判据族」——判据说 OK 但什么都没量（已经踩了 7 次）

单独写成了 [`影匠/知识/假判据族.md`](影匠/知识/假判据族.md)。六个族：

| 族 | 例子 | 差点造成的后果 |
|---|---|---|
| 读的**地方**不对 | `Test-Path 'C:\pagefile.sys'` 返回假 `False`（文件被内核独占） | 重建一个**正在用**的页文件 |
| 读的**编码**不对 | `Get-Content` 默认 GBK 读 UTF-8 → 698 条归档被读成「全部不在」 | **重新下载 20 GB** |
| **太弱**（恒真） | `探时长()` 用了不存在的 `ffprobe` → 异常被吞 → 返回 0 → 判据恒真 | 字幕时长从来没被验过 |
| **太严** | 逐字符比 ComfyUI 回执（`16` vs `16.0`）→ L2 永远红 | 天天误报，人开始无视它 |
| **作用域**没覆盖 | 「三关全过」只查模型文件在不在，一个字没查依赖 | 一跑就 `ModuleNotFoundError` |
| **两处拼路径** | 映射表反斜杠 vs 库里正斜杠 → 同一文件被判「不存在」 | — |

**最狠的一条**：三对 30 GB 文件**抽样哈希完全相同**，
**全量哈希才暴露差异** —— 按抽样判**会误删 63 GB**。

**统一规矩**：
> **破坏性动作前，用一个和主判据无关的第二判据复核一遍。**
> 说「在」的要两个说在；说「不在」的也要两个说不在。
> 只有一个判据支持的删除，不做。

### 4.2 我自己犯的：把「正常在跑」判成「卡死」

看到日志停在 `75%|██▌ | 15/20`、GPU 却 100%，判「采样卡死」，
**杀了两个出片任务、重启了 ComfyUI**。

**真相**：我拿日志时间戳去比一个**我从来没核对过的「现在」**——
我以为过了 20 分钟，其实只过了 4 分钟。格4 单独重跑 **149.5 秒**就出了。

> **凡是要说「卡住了」，先打一次 `Get-Date`。**

### 4.3 硬链接 > 删除（当用户说「有用的全留下」+「删之前核对」时）

同卷内 `os.link` 出来的第二个名字**不占额外空间**，
但每个路径都还在、都能打开、还是原来那个大小。
**省下的空间和删掉一模一样。** 用户的两条要求同时满足。

**并且：`os.remove` → `os.link` 是错的**（中间有一个路径不存在的窗口，
进程死在里面就把路径永久弄丢了 —— 子代理在两个时刻亲眼看到两份 25 GB 模型「不在盘上」）：

```python
os.link(源, 临时名)       # 数据先出现，目标还在
os.replace(临时名, 目标)  # 原子覆盖，没有「不存在」的时刻
```

### 4.4 中文的修辞，模型按字面读

「洗得发白」→ 画出白围裙。**形容词要用它字面的意思。**

### 4.5 排除项比肯定项管用

写「没有肩章、没有领章、没有金属纽扣」比写「古代武官袍」有效 ——
**模型会去凑那些词**。
