# 影匠工作台

**给一个人用的 AI 视频生产线。** 两台机器（本机 + 远端 RTX 5080）一起出片，
桌面上三个图标就能看、能操作：

| 图标 | 是什么 | 端口 |
|---|---|---|
| **影匠控制台** | 能**操作**的生产界面：起活、看进度、选片子去超分 | 8791 |
| **依据** | 常驻置顶小窗，实时显示「这一轮读了哪些文件、做了什么」 | 8794 |
| **记忆台** | 搜整个记忆库（经验、台账、知识） | 8792 |

## 几个值钱的坑（写在这里，因为重踩一次很贵）

- **帧数必须落在 17n+5 网格上**：H3 的 `length` 写 109 会被**悄悄**吸附到 124
  （4.4583 秒 → 5.1667 秒），日志和节点都不报错，只有拿 ffmpeg 量成片时长才发现。
- **远端出的片子在本机磁盘上不存在**：必须走 HTTP `/view` 拉回来。老代码硬编码本机
  `output` 路径，在远端跑时 `os.path.isfile` 永远 False → 每格都记「没出」，
  片子其实已经生成好了（白等 3 分钟一格）。
- **HTTP 请求行只允许 ASCII**：路由名写成 `/api/片` 会抛
  `UnicodeEncodeError: 'ascii' codec can't encode character '\u7247'` —— **连请求都发不出去**。
  URL 里的中文（含参数名）一律 `urllib.parse.urlencode`。
- **`SetWindowPos` 不声明 `argtypes`，ctypes 会把 64 位 HWND 截成 32 位**：
  返回 1、`GetLastError` 0，**看着完全成功**，但置顶位始终是 0。
- **判据要回读状态**：「返回成功」不等于「生效」。

## 跑起来

```powershell
# 控制台（会自己拉起本机 ComfyUI）
python -X utf8 影匠\_控台.py --口 8791

# 依据台 + 依据窗
python -X utf8 台\_依据台.py
python -X utf8 台\_依据窗.py
```

需要：Python 3.11+、一台（或两台）跑着 ComfyUI 的机器。
路径按本机情况改 `影匠\_控台.py` 顶部的 `根` / `本机Comfy`。
