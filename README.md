# 影匠

**本地 AI 影视流水线** —— 在自己的机器上，把「一句话」走完 `剧本 → 分镜 → 首帧 → 视频`，角色跨镜头不跑脸，风格可锁定，全程不花钱、不排队、不出门。

跑在 ComfyUI 上（本机 RTX 5080 / 16 GB 显存）。出图 **3.7 秒一张**（1024×1024，模型热了之后），图生视频 5B 模型本机可跑。

---

## 三层结构

```
导演.py     ← 你只跟这一层打交道。一句话就是一个镜头
  ├─ 风格库.py   23 种画风，中英双语键，编译成完整提示词
  ├─ 角色库.py   角色一致性四层锁定（文字锚 / 种子锁 / 定妆照 / 参考图）
  └─ 引擎.py     ComfyUI 的 HTTP 接口。模板驱动，不写死工作流
拼图.py     ← 把一叠镜头拼成看片表
```

**设计原则**：工作流不硬编码在代码里，而是放在 `模板/*.json`。ComfyUI 里调好的工作流导出成 API 格式丢进来，代码立刻会用。

---

## 三行就是一个镜头

```python
import 导演

导演.立戏("凌霜单骑闯关", 默认风格="cinematic-real")

导演.定角("凌霜", 性别="女", 年龄="青年", 发="银白长发披肩", 眼="紫色杏眼",
          肤="冷白皮", 服="黑色修身长袍，银色云纹刺绣",
          特征="左眼下有一颗小痣", 体态="高挑清瘦")

镜 = 导演.开镜("凌霜独自站在落雪的荒原上，侧身回望镜头，风吹起她的长发和衣摆",
               景别="medium shot")
```

`开镜()` 内部做的事：

```
风格库.编译(风格)  +  角色库.外貌串(角色)  +  你的情节
      ↓
一整条英文提示词  +  角色固定的种子（同一张脸）
      ↓
引擎.文生图 → 作品/<戏名>/<镜头>.png
```

## 角色一致性怎么锁的

同一个角色出现在 20 个镜头里，怎么保证是同一张脸？四层，从弱到强可叠加：

| 层 | 手段 | 说明 |
|---|---|---|
| 1 | **文字锚定** | 每镜都拼同一段「外貌串」，一个字不改 |
| 2 | **种子锁定** | 角色名 → md5 → 固定 seed，底模随机性收敛到同一个解 |
| 3 | **定妆照** | 先生成一张官方定妆照存进 `assets/角色/` |
| 4 | **参考图注入** | 后续镜头把定妆照当参考图喂回去 |

默认走 1+2 层，实测四镜不同景别不同动作，脸稳。

## 中文描述怎么变成提示词

提示词里英文更稳，但**你用中文写**。`角色库._译()` 的规则：

1. 整串命中词典 → 直接用
2. 按中文标点切段，每段先试整段命中
3. 段内**最长词优先**替换（两侧补空格，免得英文单词粘成一坨）
4. 替换完**还有中文残留 → 报警并丢掉**

第 4 条是关键：**它绝不把没译出来的中文混进提示词里静默糊过去**，而是明确告诉你哪个词缺了：

```
⚠ 词典缺词，这些描述**没有**进提示词：深红色斗篷（没译出：深）
　→ 补词：角色库.加词({'深红色': 'deep red'})
```

补词两种方式：改 `角色库.py` 里的 `_词典`，或运行时 `角色库.加词({...})`。已经是英文的描述原样保留。

换成上面任何一条，只要往 `模板/` 里放一份对应的 API 格式 json。

## 踩过的坑（留给以后的自己）

1. **`python main.py` 不带 `--extra-model-paths-config`** → 所有加载器返回空列表，报 `value_not_in_list`。
2. **HTTP 头只能是 latin-1** → 中文文件名上传会 `UnicodeEncodeError`。`上传图()` 现在把文件重命名成 `yj_<md5>.png` 再传，顺便去重。
3. **词典逐词替换会留下中文残渣** → 必须切段 + 最长词优先 + 残留检查。
4. **`CLIPTextEncode` 有两份（正/负）** → 不能"取第一个"，要顺着 KSampler 的 `positive`/`negative` 连线倒推。
5. **PIL 默认字体渲染不出中文** → `拼图.py` 按优先级找 `msyh.ttc` / `simhei.ttf`。
