# 影匠控制台 —— 打包成 exe（P1⑤）

## 一句话

`D:\DSHworkspace\影匠\影匠控制台.exe`（8.0 MB）**双击就能开**，不需要装 python，
不需要装任何依赖。桌面上的 `影匠控制台` 图标起的就是它。

## 怎么打的

```
python D:\DSHworkspace\_打包控制台.py
```

它干三件事：① 用 PyInstaller `--onefile` 把 `影匠\_控台.py` 打成 exe；
② 把 `_出H3.py` / `引擎.py` 用 `--add-data` 塞进包里（直调那条路要用）；
③ 把成品拷一份到 `D:\DSHworkspace\_打包\装\`。

## 三条必须知道的

### ① exe 必须待在 `D:\DSHworkspace\影匠\`

它**认自己所在的目录当根**，然后在那个目录下找 `作品\`。
搬到别处去，它会说「作品\ 下没有戏」—— 那不是坏了，是它找错地方了。

### ② 打进去的 .py，PyInstaller 不会自动分析它们的 import

PyInstaller 只顺着**入口文件**（`_控台.py`）的 import 图找依赖。
`--add-data` 进去的 `_出H3.py` 里那句 `import uuid` 它**看不见** ——
于是 exe 起来、页面全绿、按了「开始」才炸：

```
ModuleNotFoundError: No module named 'uuid'
```

（2026-10-15 实测踩到，第一条直调就炸在这儿。）

所以 `_打包控制台.py` 里用 `ast` 把「打进去的 .py 顶层 import 的标准库」
减掉「入口已经 import 的」，再逐个 `--hidden-import` 塞进去。
实测算出来的是：`hashlib`、`mimetypes`、`random`、`uuid`。

### ③ `--onefile` 的 exe 跑起来是**两个进程**

一个 8 MB 的 bootloader + 一个 40 MB 的真身。
跟 venv 的 `python.exe`（shim）一个道理 —— **看到两个同名进程不是端口冲突**，
别去杀那个小的。

## 打完之后能干什么

| 活 | exe 里能跑吗 | 为什么 |
|---|---|---|
| **直调·出段（本机 / 远端）** | ✅ **完全能，不需要任何外部 python** | `_出H3.py` / `引擎.py` 只用标准库，被打进包里了，`importlib` 直接从解包目录导 |
| 出首帧 / 配音 / 总装成片 / 超分 | ⚠️ 要机器上有一个真 python | 这些是另起子进程跑磁盘上的 .py。exe 会自己去找 `ComfyUI\.venv\Scripts\python.exe`；找不到就在按「开始」时明说，不会静默地跑错 |

## 验证过的（2026-10-15）

- exe 起在 8795，`GET /` → **HTTP 200，12,850 字节**
- 在 exe 上点「直调·出段（远端）/ 觉醒 / 格18」→ **175 秒**出
  `D:\DSHworkspace\影匠\作品\觉醒\段\格18_远端.mp4`（**2,095,998 B**），
  退出码 0，控制台计数自己从 段远端 29→30、段齐 1→2
- 桌面 `影匠控制台.cmd` → 8791 → HTTP 200
